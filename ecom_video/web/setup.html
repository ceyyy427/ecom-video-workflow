本机环境

安装依赖只需首次进行。检查不会合成声音、调用视觉模型或操作平台。软件存在不代表实际渲染已验收。

    缺少基础工具时，退出启动窗口，按完整安装指南安装后重新双击“启动剪序.command（macOS）或启动剪序.cmd（Windows）”。不要删除已有的 var 数据目录。

    02

    本机模型

    自动识别和字幕对齐使用不同模型，不会把商品图片发送到云端。也可先用手动选段和纯商品展示开始。

    视觉识别 · 实拍内容与选段

    没有候选？打开本机 Ollama 应用，安装支持图片识别的本机模型，再点“重新检查”。不支持云代理模型；本页面不会自动下载视觉模型。先暂停/取消待执行任务，再切换模型。

    字幕对齐 · FireRed ASR

    从项目固定的官方 Hugging Face 仓库下载，约 750 MB，以项目记录的 SHA256 校验。已有完整模型只做校验；下载总量上限 900 MiB、总时限 15 分钟。网络中断不会启用残缺文件。

    03

    声音 · 可稍后配置

    使用豆包语音新版控制台的语音 API Key，不是火山方舟大模型 Key。确认同项目已开通“语音合成2.0字符版”、Key 启用。也可直接上传客户成品配音。

    保存不会发送文稿、试听或验证账户权限。文稿和风格确认后，在制作页勾选发送与计费说明，再试听和合成。配音仍须逐句人工听核。

    配置就绪后，在制作页主动试听，再逐句听核；保存配置不会自动确认任何文稿或成片。

    遇到问题，按提示继续

    配音资源未授权 / 45000030 / 401 / 403

    45000030：在豆包语音新版控制台确认 Key 所属项目的“语音合成2.0字符版”已开通，未暂停，Key 启用。401：核对是否误用了方舟 Key。403：核对项目和访问权限，不能仅凭此状态确定是哪项缺失。配置后回制作页明确授权试听；本页不自动重试或产生计费。

    配音与文稿匹配不足、字幕对齐失败

    先核对是否用了对应原稿和完整音频，留意型号、数字和多音字。制作页可查看识别文本和历史稿，选择对应文稿或换配音，再重做对齐。少量时间插值仍须人工听核；明显内容不一致不能自动改成“通过”。

    视觉模型未就绪 / 桌面镜头错选

    打开 Ollama，重新检查并保存支持图片的本机模型；不要选择带 cloud 的模型。用清楚的同款商品参照图，并检查动作选段。识别是建议，不代表事实或同款已确认；也可切换手动选段。

    下载中断 / SHA 校验失败 / 磁盘不足

    留出至少 5 GiB 工作空间。检查网络后重新点安装，不会自动无限重试。若已有 firered 目录不完整，先停止任务，用文件管理器打开安装目录的 var/models，把该目录移到旁边留存，再重新安装。不要删除整个 var。退出服务会中断下载，再次启动需重试。

    生成失败 / FFmpeg、Node.js、字体或浏览器缺失

    先看第一步的具体缺项；Node.js 需 22 或更新版本。基础依赖和 Remotion 浏览器由首次安装脚本准备。异常中断后可按完整指南重新安装项目依赖；不要在渲染时重新安装。中文缺字时配置中文字体后重启，再重试失败任务。

    启动打不开 / 端口占用 / 页面会话更新

    同一安装目录重复双击会打开现有客户实例；其他程序占用 8765 时会提示，启动器不会关闭它。先退出占用的服务再启动。页面提示会话已更新时刷新后重试。请先保存编辑并等待任务完成，再在启动窗口按 Ctrl-C 停止该实例；关闭网页不会停止服务。
