01 / 上传资料与素材

打开“商品制作”，新建项目或选择已有项目。选片种、填写制作要求并保存，再上传产品资料（TXT / MD / PDF / DOCX）、图片和实拍。成品配音可直接上传，也可确认文稿并选风格后再合成。片种支持纯商品展示、场景种草、测评、商品展示＋配音；测评还需测试条件与证据。

自动选段使用本机模型；商品参照图可帮助核对，严格同款核对时需先选择清楚的参照图。识别后仍须检查主体和动作是否正确。也可关闭自动选段，人工设置素材用途与实拍入点。参照图可仅用于核对，不必入片。图片不能替代真实使用或测评证据。

先核对现有素材能做什么

已有识别结果可点击“复核识别”：严格校验文件、参照、模型与帧证据后复用原始观察，动作事件重新计算；页面显示本轮耗时。需要全新判断时点击“强制重新推理（较慢）”，旧记录保留。全新素材首次仍需本机推理。现已针对验证过的本机模型优化GPU驻留和请求顺序，支持的本机配置会按任务独立加速并在结束后退出，其他配置保留原服务；小内存Mac会回收运行缓存，页面显示推理耗时及资源降级提示，不减少同款、主体可见度和动作完整性检查。强制重推不会读取旧判断，仍可能耗时数分钟。缓存不代替人工听核与审片。

新建项目默认开启“增强素材检查”；旧项目先开启并保存，再重新识别。需选择清楚的同款参照图。脚本备选与三个风格会显示可用、缺口和待核对项；配音完成后按实测镜长重查。外观比较忽略液体与握持变化，但不是SKU鉴定；连续抽样不能证明未抽到的每一帧。

主体过小、遮挡、错款或动作缺开始/结束时，不自动拿背景或静图顶替。相同源时间区间不重复使用；不同文件的相似帧仅提醒。开合盖与倒入有有限动作证据规则，其他动作仍需人工判断。可补拍、重新识别或逐镜人工选段；旧片保留，人工选择不伪装机器通过。查看实拍检查、缺口和单镜对照 →

按人群和气质匹配商品画面

打开完整镜头参考库：124卡 / 150风格变体 / 150样例索引。可检索完整Prompt、参数、已知问题与固定版本代码来源；未适配的参考不会自动执行。

第二步可点击“预览三份备选稿”：本机以完整确认事实编排整体、细节、场景三种讲法，预览不会替换当前稿。明确采用后生成待确认草稿；人工确认后再选风格、试听配音。素材不足不会凭空生成动作、数据或价格。新版同一条片逐句匹配细节括号、完整原文信息行和媒体层场景交接；数据/销售句须精确引用当前事实，长句或缺依据会提示，不截掉适用条件。看27秒逐句混合编排和单镜对照。

在“商品制作”第一步选择片种，填写或点击标签添加目标人群与希望气质，再保存。确认文稿后，第三步会给出三个方向；点选后可展开“Prompt与画面依据”，查看关键词命中、参考来源、素材要求和三个镜头建议。

本机38张版本化项目Prompt卡（15张来源卡有限适配，109张仅参考）覆盖原通用卡与美妆包装、食品、服装、家居收纳和工具，包含镜头目的、取景要求及听读配合。完整库124卡/150变体只作为可检索参考，未适配不会执行。新增字形展开与同帧分区；气质明确包含“视觉冲击、字形、分屏”等词时参与推荐，普通气质继续原来三类实拍动效：商品局部急推、整体与细节同帧双窗、形状窗口展开。每种方向有不同节奏变体，文稿动作句和收尾保留连续观看。未满足清晰度、镜长或动作保护要求时会保留基础画面，不凭Prompt生成没有证据的商品动作。

分镜中可以选择或关闭某一镜的“商品画面Prompt”，修改焦点、取景和保护区间，再单独生成新版。横屏素材可能仍偏小，方形取景须人工检查商品、双手和全过程；局部窗若没有对准瓶口/接口，请调垂直/水平焦点并生成新版回看，关键词匹配不等于自动跟踪；静态风格帧不代表成片质量。仍需逐句听核和成片审核。查看滴管瓶新类别三方案 · 查看耳机三方案。

02 / 确认事实、文稿和三个风格

  1. 逐条核对资料来源，选中真实事实，填写确认人和说明后确认。
  2. 确认事实后，可按已保存的制作要求生成文稿；已有配音时粘贴其原稿，每行一句。新生成稿始终待确认；检查每句事实引用、镜头目的和素材建议，填写文稿确认人和说明，再确认文稿。修改要求后先保存，再点“按制作要求生成新稿”，不会覆盖旧版。
  3. 先在第一步填写并保存商品类别、目标人群和希望气质。确认后会从九种视觉方案中推荐三个方向，显示匹配理由和配音节奏。相同输入结果稳定，修改内容再保存后重新计算；已有成片保留。点击一个方向。风格预览可稍后生成；缺素材或准备失败时按页面提示补齐，再点“使用已确认文稿，继续制作”。
  4. 需要合成声音时，选风格后在“为这个风格配声音”试听当前稿件首句，可换音色；勾选发送与计费说明后再合成整稿。换声音会保留历史，并重新准备和对齐；不会自动听核或审片。
  5. 本机字级对齐完成后逐句试听，必要时展开校正时间戳，填写听核人并确认。内容不一致须换稿或换配音，不强行对齐。纯展示无需配音听核。
  6. 点击素材缺口检查，按每句提示补资料、补实拍或核对识别。检查只读，不自动批准；图片或“可折叠”等能力描述不能证明动作发生。明确缺口会阻止自动选段；也可明确切到人工选段，核对真实区间后继续。
  7. 点击“选定风格并生成分镜”，预览每镜并调整素材、入点、字卡、运镜和裁切。

每镜 1–15 秒，总长≤120秒；短实拍不循环补长。事实、文稿、风格、听核均由你确认。本机自动执行也会在人工确认处等待。

03 / 生成、审片与交付

点击“生成成片”，完成后停在“待人工审片”。完整观看商品一致性、事实、字幕、声音和素材许可，填写审核人、意见并确认通过后交付。可查看综合审核并下载冻结 JSON / HTML 报告、MP4、SRT 和分镜记录。报告标明实际执行及未检查项目；启用本机媒体审核后会抽帧识字、识别最终音轨并定位差异，缺失证据不会当作通过。它不代替事实、授权、商品一致性和平台审核；每镜可试听对应配音；声音不满意可用“只重做这一句配音”，对比旧新声音并人工采用，再听核新版；不满意的画面可单独修改，保留旧版、原配音和其他镜头缓存。完整声音可从历史恢复，首句试听不能用于成片。修改文稿或声音需重新确认和对齐。

审核通过后去“数据复盘”。客户在平台自行上传成片、设置商品、预算与排期并完成平台审核；保存广告主 ID、平台素材 ID、上线日期及本地成片版本。素材 ID 不等于计划 ID。本地审核不等于平台审核。

04 / 导入、关联、冻结复盘

  1. 在“数据复盘”登记广告主账户；CSV 模式无需 App ID 或 Secret，也不代表平台授权。
  2. 选择账户和日期范围。下载 CSV 模板，将客户导出的完整素材日报映射到模板，金额 CNY、自然日 Asia/Shanghai。缺失值留空，真实零值才填 0。
  3. 展开“导入平台 CSV 报表”，填写导入人。归因窗口只照抄客户实际导出设置并单独确认；未知留空，不能照抄示例来通过对比。
  4. 展开“关联平台素材与本地视频”，人工将素材 ID 绑定到确切的已审核成片版本。
  5. 核对实时复盘、缺失与口径后，填写冻结人并确认，保存冻结快照。记下复盘 ID，可从历史重开和下载 JSON。

重导会更新实时数据；已冻结的报表、当时关联、版本与创意特征不改写。不要把实时 JSON 当作已冻结证据。只读接口作为可选接入保留，当前流程不要求制作者有投放账户。

05 / 从冻结素材提出创意假设

在冻结素材卡点击“基于此冻结素材提出创意假设”，自动带入基准复盘与素材。填写实际记录人，读取依据，写假设、观察指标和门槛；选择单镜画面修改或改稿。镜头修改参数目前使用页面标注的 JSON 数据。

保存提案不会改片。先人工选择并说明，再点“应用为新版草稿”。父片、旧复盘和来源保留。改画面后打开商品制作核对分镜，重新听核本版；再从顶部链接回迭代页确认当前风格。改稿须先去制作页确认新稿和匹配配音、准备草稿，再回迭代页关联该新稿草稿。关联后回制作页完成听核、选择方向并生成和核对分镜，再返回迭代页确认当前分镜风格。

确认风格后返回制作页生成、人工审片，随后回迭代页记录“等待客户数据”。这只记录进度，不操作平台。

06 / 下一轮冻结与对比

客户自行投放新版后，回“数据复盘”导入下一轮日报，绑定新版素材 ID 到新版已审核成片并冻结。回原提案，读取下一轮复盘 ID、选择该新版素材，保存描述性评估并下载迭代 JSON。

只比较账户×素材×日。日期须等长、不重叠且下一轮更晚，指标口径、币种、时区、归因窗口须一致，并满足人工设定的天数和曝光门槛。缺数据、未知口径或对应不明时显示证据不足，保留原值与原因，不补零或判优。重导后另存新冻结与新评估，旧结论仍保留。

CTR 从10%到20%是增加10个百分点；支付 ROI 是支付金额÷花费，不是利润率。变化可能来自流量、人群、预算、日期等，本系统不作因果归因、不选胜者、不自动投放。

交付客户前还要完成什么

当前适合单客户、单SKU、有人操作的本机试用。客户提供真实资料、授权实拍和正确型号后，选三种方向制作，逐项签收画面、事实、声音、字幕与许可。示例道具和技术测试不等于客户签收。

改单句后要对比旧新声音，核对其余镜头、字幕和旧版本，重新听核审片。已提供本机自检、逐文件备份校验和恢复到新目录的维护工具，见下方“本机自检与数据保护”。正式交付前仍需在客户机器验证安装、模型、磁盘预算、备份恢复和故障继续；Windows尚未实机验收。平台由客户操作，先用真实CSV做复盘，有授权后再联调只读账户。

能力矩阵与交付门槛保存在仓库 docs/CAPABILITY_MATRIX.md。不能把本机版直接作为公网多租户服务，也不承诺广告效果或因果归因。

高级入口、继续工作与接口

日常从“商品制作”继续已有项目；中途关闭可恢复已保存内容。完整分镜工作台保留旧任务，创意工作室用于字级校正、风格和高级设置。未保存的编辑须先保存。迭代页可从最近提案或完整提案 ID 继续；复盘页可按冻结 ID 重开。
