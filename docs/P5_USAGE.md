# P5：风格选择、口播与可复用制作

打开 `/studio`，选择已有任务。先在制作任务页保存脚本和上传素材，然后填写商品类别、受众/场景与气质，点击“生成三个推荐方向”。系统用本任务素材实际渲染三个风格帧；点击一个方向，填写品牌名和颜色，调整动态字卡与素材用途。字卡只能摘取本镜原文，不能绕过商品事实确认。

第一版为本地可解释推荐：使用商品描述、已确认脚本和素材类型评分，不宣称具备视觉识别或自动品牌理解。六个受控模板为质感杂志、细节解说、生活剪贴、几何陈列、安静日常、节奏字卡。每次返回三个，不随机换色凑数。素材不足会列出补充建议，不会自动生成商品性能证据。三个预览为首镜风格帧，最终成片还须审片。

## 口播制作

1. 文稿每行一个语义拍，单拍 1–15 秒，全片不超过 120 秒。上传与该文稿对应的一条成品配音；若另有音乐，总计最多两条音频。
2. 在创意工作室选择配音，点击本机对齐。音频不会上传云端，也不会自动剪除停顿。
3. 等待进入“待听核”。点击句子回听；黄色提示插值字或低匹配句，可逐字修改开始/结束时间。填写听核人，确认后应用口播时间。
4. 保存方向与镜头，然后回原分镜页检查选段是否足够长；调整图片焦点、推拉横移、完整显示/铺满。上传配音模式中，每镜必须覆盖相应句子，不能任意移动切点截断人声。
5. 点击生成。最终 MP4、无背景音乐版（有音乐时）、SRT、manifest、SHOTBOOK 都保留。任务仍进入人工审核，不会自动标成可交付或发往平台。

技术上是 FireRed CTC 识别词时间 + 字符编辑距离/同音匹配；未匹配文字插值，并非音素级强制对齐，亦不保证每字误差在一帧内。数字、英文品牌名、口音和录音噪声仍需听核；过低匹配拒绝生成对齐结果。建议稿件数字写成实际读法。示例使用本机合成声音，只用于链路验收，不代表真人配音质量。

## 修改不推倒重来

草稿可反复保存镜头；已提交版本保持不可变，复制为新草稿后修改。源素材与时间参数保留。复制版本保留品牌预设，需重新选择方向、重新确认配音，以免沿用旧确认。P5 改脚本也保留镜头编辑：同句数沿用镜头，增删句子保留匹配的旧镜；不再属于原句的字卡清空，方向与配音确认失效。不会自动回退到 P4 渲染。

Remotion 只渲染静音镜头片段，以素材 SHA256、镜头参数、字幕锚点、品牌、源码和依赖摘要作缓存键。修改一个镜头，在其他镜头输入不变时复用缓存；更换品牌/字体或渲染实现会失效相应缓存。字幕时间按镜头相对位置计入缓存。背景音乐/增益修改只重混整条音频。音频全程一次混音/编码，避免片段 AAC 延迟累计。首版使用硬切，尚无跨镜转场依赖。

音乐有人声压低和淡入淡出，最终两遍响度归一；轻提示音是项目原创合成音，并非已录制的影视 Foley 素材库。“影视级效果”仍需客户提供合适的录音、音乐和声音设计参考，不能由提示音开关保证。

## 部署与依赖

`uv sync --group dev --group browser` 安装锁定 Python 环境，`npm ci --prefix render/remotion` 安装锁定 Remotion 4.0.519。运行 `uv run python scripts/setup_p5.py` 明确下载本机模型，约 740 MiB，按 `P5_MODEL.json` 的版本和 SHA256 校验；日常制作不自动下载。当前机器优先使用已安装 Google Chrome。其他机器可让 Remotion 下载其支持的 Chrome，需联网。

`sherpa-onnx-core` 显式锁定解决 macOS 动态库缺失。若 PyPI 网络失败，使用可信镜像下载相同 wheel 并核对 uv.lock 中的 SHA256；不关闭 TLS 校验。

## 客户投放与复盘

客户在自己平台账号上传、创建广告和投放。我们输出视频与素材信息，并接收客户导出的投放报表做复盘；保留平台接口，但默认不开启广告写操作。无需你先申请广告主账号来验证视频制作。

## 停止、重试与手机检查

对齐过程中可点击“停止对齐”；改稿或取消任务也会终止正在执行的识别进程。识别期限180秒，超时标记失败，允许重试。切换配音会清除当前听核状态，旧响应不会附到新音频。

默认字幕64px，最终示例实测字高60px。主动降低字号后请用手机检查。声画时间仍需听核，不能只看“锚点覆盖100%”。默认短口播按语义切镜，未强制套用发布会影片的3秒动作弧。

新建任务→上传商品图片/视频与稿件→创意工作室生成三个方向→点击一个→品牌/字卡→选择配音并听核→保存→原分镜页调选段和焦点→生成→审核。已有样片从 `/samples` 进入“查看分镜 / 复制编辑”，复制后可换商品继续制作。
