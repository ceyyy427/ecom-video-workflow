# P6 / 商品视频的四种片种

入口：本机 `/studio`（创意工作室）与 `/samples`（样片库）。先建任务、保存真实稿件并上传商品素材。新的草稿默认“商品展示＋配音”；旧版任务保留原来样式。

| 客户需求 | 选择片种 | 素材与制作重点 |
|---|---|---|
| 纯商品展示 | 纯商品展示 | 商品全貌、细节、场景；分镜页关闭配音，以短字卡和音乐表达 |
| 种草视频 | 场景种草 | 真实使用场景、适用人群与已确认卖点；不自动编造“我用了多久” |
| 测评视频 | 测评视频 | 填写条件/方法/结论来源；至少一个视频证据镜头，逐镜写来源；需要解说和人工审核 |
| 商品展示＋配音 | 商品展示＋配音 | 稿件＋成品配音→本机对齐→听核；或在原分镜页选择本机合成声音 |

每次推荐三个方向：形与留白 / 桌边的一刻 / 先看细节。根据片种、商品描述和素材类型排序，仍是规则推荐，不是视觉模型审美评分。用户可以选不同于第一推荐的方向。

选方向后，每镜可选开场露出、细节聚焦、双窗观察、场景展开或收尾停留；支持直接切接、遮罩擦拭与开幕露出。动态标题仍只能摘自本句原稿。素材入点、焦点、推拉横移、完整显示/铺满仍在原分镜编辑器中调整。新编排适用于三种P6方向；旧版方向继续使用原渲染语法。

纯展示不会允许带口播提交。其他三种片种提交前需要上传或本机配音；上传声音仍须完成对齐与听核。测评检查只确认资料结构齐全，不能证明测试是真实的，所有结论仍须客户人工审核。只有照片时，可做外观解说，不应把它称为性能测评。

## 修改与复用

镜头内改素材、选段、焦点、字卡或编排，只重渲染受影响镜头。转场由下一镜的进入类型决定上一镜退出，所以修改进入转场会同时影响前一镜；这是必要的邻镜依赖。语义字幕优先按原稿停顿切分，保留小数、百分号及英文词。整条配音不分段编码，切接不会缩短口播时间。

首镜静态风格帧仅用于选择构图；完整动作和音效请看样片。截图/照片合成不能代替实拍操作，真实演示仍需客户视频。长镜头开场才用完整5秒字形动作；短开场自动用普通露出，避免把长动作挤进短镜。

## 三支演示片

同一虚构随行杯，三种不同稿件和声音方向：形与留白18.4秒无口播；桌边的一刻约21秒；先看细节约21秒。后两版使用本机合成声与真实本机ASR，非真人录音；片内持续标识AI示例图。用途是客户风格沟通样片，未冒充正式商品广告或测评。客户正式片应替换真实商品素材、品牌信息与已授权配音，再听核审片。

平台上传、建广告与花费由客户操作；本系统保留接口、导出与报表复盘。P6未触发平台写操作。

SRT保留整句时间，烧录字幕按短语显示；文字一致但切分不同，SRT并非逐帧复制的字幕工程。扫描取景框是可控模板构图，不是自动物体检测，换素材后须调整裁切并复核。
