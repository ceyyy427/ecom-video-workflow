# 公开源码快照

本仓库用于展示剪序的可运行程序、技术方案、工程测试和使用文档。公开日期为2026-10-20。

## 发布范围

包括API与业务逻辑、数据库迁移、网页、Remotion源码与依赖锁文件、安装工具、工程测试、使用文档及必要的第三方许可。`PUBLIC_SOURCE_MANIFEST.json`记录初始选取文件的来源SHA；README、公开版说明、路径去标识及测试夹具整理在此基础上完成。

不包括运行数据库、客户目录、上传资料、原始素材、音视频产物、密钥/凭据、模型、依赖目录、私有验收记录及完整第三方仓库。样片页读取本机已经生成并登记的作品；全新克隆没有历史图库属于预期状态。

五份只含通用Prompt定义的兼容性快照整理到 `tests/fixtures/compatibility/`，相关测试只调整引用路径。涉及一份私有客户历史识别记录的测试，缺少原证据时明确跳过，未用模拟客户资料冒充历史原件。运行时业务逻辑未因此简化或降低门槛。

## 验收

本次发布前在独立源码目录执行Python回归、Node/VM、Ruff、Remotion类型检查与Yelp detect-secrets 1.5.0离线密钥扫描，结果见 `PUBLIC_VALIDATION.json`。Gitleaks官方二进制下载不稳定，未完成安装，不将其记为已执行检查；替代扫描不验证或调用任何疑似凭据，所有候选项逐类复核。

公开目录首次回归暴露了单句配音测试对开发机模型文件的依赖。测试已改为使用明确标记的临时模型占位文件，同时保留原识别调用替身；这些文件仅服务单元测试的就绪检查与指纹，不是有效模型，不随运行数据安装。程序本身仍要求真实模型就绪。

真实浏览器布局用例按用户约定排除，未使用Computer Use。未运行收费试听、正式账户写入或客户人工审批。没有重新宣称Windows真机、客户SKU样片和真实投放效果通过。

## 后续更新

公开仓库是从本机完整工作目录提取的独立源码快照。后续更新应继续采用源码白名单，不要直接把完整工作目录 `git add .` 后推送。尤其不要上传 `var/`、`client-projects/`、原始媒体、`.env`或私有语音配置。

原有使用说明有不同阶段的历史上下文，以当前README和源码为准；私有验收链接不随公开版分发。第三方许可证不会自动变成本项目整体的许可证。
