# 从想法到六个动态预览

在工作台左侧打开「创意实验室」（`/ideas`）。保留原来的页面样式、客户项目和制作入口。

## 先比较，再制作

1. 填写想法。主题名、人群和希望的气质可选，填得具体更有助于区分方向。
2. 展开「添加事实、数据与素材」。每条事实按 `完整原文｜来源` 填写；数据按 `标签｜数值｜单位｜来源` 填写。没有数值，就展示文字依据，不补造图表。
3. 可以上传图片、实拍视频，也可以引用已有项目里的画面。核对使用范围、填写来源，调整视频入点。最多选8份；视频入点后至少保留4秒。当前支持竖版预览，横版素材保持比例。
4. 点击「生成六个动态预览」。后台按顺序在本机渲染；可以取消，或重试未完成的方向。正常一键启动需同时运行工作进程，不能只启动网页服务。
5. 看完七秒预览和文稿，再点「采用这个方向」。详情里可下载冻结方案JSON，下载不记录审批。页面会给出「进入客户工作台」的链接。
6. 新项目带入本次资料、原文稿、素材、配色与镜头配方，所有审批为空。先核对事实，页面再带入所选文稿；文稿、方向、最终分镜、配音听核和成片仍按原流程确认。默认先以纯展示方式准备，想做口播可在工作台切换片种、明确选择配音并试听。

预览是**静音画面草案**，360×640、30fps、7秒；海报由真实渲染取得。它不代表成片审核通过，也不是新商品的外观证明。完整制作继续使用现有渲染器和逐镜编辑。

## 首批六种结构

| 方向 | 重点 | 本机执行 |
| --- | --- | --- |
| 关键词冲击 | 短标题落位、重点急推 | kinetic＋关键词/局部推近 |
| 结构拆解 | 整体、细节与关系 | lab＋聚焦/同源双窗 |
| 资料说明 | 完整原文、有来源的数据 | evidence＋信息卡/信息行 |
| 纸张叙事 | 逐页讲述、纸张层次 | collage＋形状展开/词组浮现 |
| 聚光发布 | 主角登场、克制留看 | cinema＋字形展开/聚光舞台 |
| 节奏剪辑 | 连续实拍、同帧分区 | social＋急推/分区/讲解接力 |

这些是依据固定版本参考资料做的首批适配，不能等同于上游完整作品。59套资料仍可通过「只查参考」查看；其余方向没有冒充已实现模板。

没有素材时使用明确标识的代码图示，只显示输入文字与数值，不生成虚构商品、人物或场景。人群、气质会改变排序、讲法、时长分配和动效强弱；事实原文及数值保留。

## 修改与恢复

- 修改输入后，旧方案的「采用」按钮会停用；重新生成后再选。旧方案和成片不会被覆盖。
- 采用后沿用原工作台的逐镜修改、影响预告、版本对比及恢复。恢复切回已保存版本，保留该版本原有审核记录；继续修改时另建待审版本，不增加审批。
- 改了文稿，旧代码图示的文字不能自动充当新事实。本期会明确拦下，需重新生成方案或替换对应图示；不会悄悄显示旧内容。
- 已有自动选段的素材和安全入点优先保留。原速动作保护、同款限制与主体可见检查继续有效；缺证据仍显示未知。
- 预览使用独立的冻结素材副本。原项目移除素材，不会连带删除已有方案的画面。

## 常见提示

| 提示 | 怎么处理 |
| --- | --- |
| 一直排队 | 确认一键启动仍在运行；已有制作任务优先，预览随后执行 |
| 素材不足／完整动作会被截断 | 调整入点、换素材或补拍；不会靠循环、冻结或变速填充 |
| 来源资料尚未确认 | 在客户工作台逐条核对；需要显示的数值也须确认 |
| 预览文件缺失或变化 | 点击重试；有效方向保留，只重新生成损坏项 |
| 渲染引擎已更新 | 按当前输入重新生成一套方案；旧预览仍可查看，不混标引擎版本 |
| 图示文字与当前文稿不同 | 更新该图示或重新生成方案，再确认分镜 |

本页不调用云模型、不生成配音、不写入投放平台。后续明确选择现有配音服务时，仍遵守原有配置与听核步骤。
