# 国内运营候选版能力矩阵

0.18.0，Apple Silicon Mac。本机工程验证与客户实际验收分开。

| 环节 | 当前能力 | 交付边界／待办 |
| --- | --- | --- |
| 资料与事实 | 文件/链接输入、来源SHA、SKU/单色约束、版本确认 | 需客户有权使用素材，并实际确认商品事实 |
| 商品定位/口播 | 当前事实约束的完整原文与口语候选，人群/气质/素材缺口 | 有限本机规则，不是任意题材的自由生成大模型；稿件仍需人定 |
| 六方向 | 三种讲法各两套结构，真实7秒动态草案，采用后进入制作 | 静音预览；缺素材不编造外观/动作，已提供画面仍需核对 |
| 执行与恢复 | 复用有界Runtime，原预算、取消、暂停恢复、回执与旧任务 | 默认尊重原启用开关；无新云/平台写权限，结果不明不重发 |
| 成片 | Remotion/FFmpeg，实拍选段、动效、关键词字幕、声音时钟、完整动作 | 作品美感由实际看听判断；工程重渲不等于客户签收 |
| 本机识别/ASR | 原后端及固定权重，明确缓存复用路径与SHA | 本轮不宣称首次视觉识别提速；不降检查标准或切默认后端 |
| 配音 | 已有上传/火山通路，独立可选VoiceStudio接口 | 新音频实际试听后确认；本包不带第三方应用或模型，不默认调用付费API |
| 逐镜修改 | 影响预告、旧版保留、对比恢复；无关镜头缓存 | 时长/跨镜转场变更仍按实际范围重做，不保证所有编辑都只影响一镜 |
| 市场/毛利 | 授权样本、币种分组、缺价保留；完整费用与生效区间的Decimal试算 | 不抓私有竞品，不推断市场规模，不自动改价；未填费用未知 |
| 封面/图文 | 本商品实际素材/帧＋事实原文；缺图使用标记代码图示 | 需审核素材、版式及使用权；不伪造商品照片 |
| 发布交接 | 版本SHA、视频、已有SRT/封面与待审文案ZIP，作品ID人工映射 | 客户自行发布/投放；导出不是审批 |
| 平台只读 | 抖音固定本人作品适配、OAuth/Keychain；小红书授权CSV | 抖音真实账户权限/回调仍待实接；小红书笔记API unavailable，浏览器MCP关闭 |
| MCP/n8n | 官方MCP2.3.0可选依赖、内存协议验证；n8n只读示例 | 不默认安装，不将readOnlyHint当权限；不运行发布工具 |
| 冻结复盘 | 平台×账户×作品×日，来源与成片特征绑定，累计/每日、缺失/零分开 | 真实客户报表尚待导入；不混广告口径、不推断因果 |
| 评论/下一版 | 本机规则候选、行证据、隐私最小化、人工选假设、新项目待审、两轮对照 | 非完备语义/隐私模型；须真实下一版绑定和可比期间，不代替人工审批 |
| 安装/升级 | 一键启动、自检、页面配置、备份/恢复/独立升级；固定资源随包 | 本轮主验Apple Silicon Mac；Windows仅保留原代码，等待目标机验证 |

操作见 DOMESTIC_SUITE_GUIDE.md。已知限制不是隐藏的自动能力；真实人工确认、账号联调和最终发布仍待客户。
