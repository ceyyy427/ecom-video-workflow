# Huashu Motion 方法接入与两品类精修

2026-10-18。用户要求本轮禁止 Computer Use；本轮不用 CUA、浏览器自动化或旧的 Playwright 页面验收脚本。Remotion 在程序内部离屏渲染 MP4 继续使用；没有操作用户浏览器，也没有用其他 UI 自动化替代禁用工具。

## 看到了什么，采用什么

[Huashu Motion](https://github.com/alchaincyf/huashu-motion) 固定提交 `3e927801e78b587878fb7dbb65d616326df00c21`。其代码和方法文档为 MIT；[THIRD_PARTY.md](https://github.com/alchaincyf/huashu-motion/blob/3e927801e78b587878fb7dbb65d616326df00c21/THIRD_PARTY.md) 明确第三方字体、GSAP 另有许可，作者卡通角色不在 MIT 内。只下载13份必要文本，哈希见 `vendor/huashu-motion/SOURCES.json`，许可证在 `docs/third-party/huashu-motion-LICENSE`。没有下载其引擎、编辑器、字体、乐器采样、模型或角色；不执行上游脚本、Prompt或全局安装，不添加客户运行依赖。

本轮采用的是产品讲解方法：

| 方法参考 | 在本项目的实现 | 明确边界 |
| --- | --- | --- |
| 先选运动语言 | 推荐卡片同时显示实拍/字卡/观察式方向及连续或混合路线 | 依据商品文稿、人群、气质的本机词表匹配；不是通用审美模型 |
| 节奏有起伏 | 新规划区分开场、铺陈、一处可用镜头加强、动作减弱、收尾留看 | 不为追音乐节拍剪断动作，不强行在动作镜制造高峰，不伪造拍摄 |
| 落定后阅读 | 导出原稿、实际cue、转场入场/出口、估算标题稳定窗口、字锚点 | 这是已知动画时序估算，不是像素遮挡检测或“好看”评分 |
| 局部返工 | 新版只第三镜关闭精修，比较其他场景文件SHA、配音和最终PCM | 跨渲染引擎首次缓存失效仍可能发生；同引擎内单镜复用单独验证 |
| 工程与作品分开验收 | 技术回执绑定最终MP4 SHA；所有样片待真人听核/审片 | 测试数、帧差、响度不能替代客户画质签收或人耳判断 |

这些是工程采用和本轮试用，不复述上游关于顶级质量、速度、广告互动效果的宣传数据，也不将其少量品类研究当作我们客户的效果证据。没有新增作曲器、云配音、视频生成模型或第二套渲染器。

## 客户流程中有什么变化

1. 商品资料、目标人群、希望气质仍参与三个推荐，卡片增加“实拍为主/运动语言/节奏主次”的说明。相同输入结果稳定，变更输入后重新计算；少量措辞变化不保证三个ID全换。
2. 选择方向、确认文稿和配音后，新分镜使用 `polished-v1`：实测标题、可靠字锚点轻强调、字幕在转场上方。强度在新规划中有区别，动作段减弱，收尾停住；逐镜编辑仍可调整。
3. 原有分镜不会被后台重编排；历史电影保留。manifest和SHOTBOOK新增 `motion_treatment` 回执，标明镜内/全片时间、全片落定及强调时间、短阅读窗警告。旧版动画不套用新落定估算。
4. 修改画面保存新版本，只重渲对应镜头。事实、文稿、风格、听核、成片审核继续人工，不自动投放。没有数据库迁移。

## 两个验证商品与授权

复用已留档的 黑色耳机与棕色滴管瓶许可来源（历史记录或本机文件，未随公开版分发）：Pexels 9130353、9130365、7607242，以及对应的既存普通合成配音。该许可允许使用、编辑和宣传，但不得暗示画中人物背书、出售未改动副本或再分发为素材库存，见 [Pexels 官方许可](https://www.pexels.com/license/)。本轮复核官方许可与商品素材页；原片缓存按原SHA核验，不新增云请求，不公开原stock下载接口。

耳机只讲外观、头梁、耳罩、收拢与佩戴；滴管瓶只讲包装、旋开与提管，不称为真实音质/降噪或护肤功效测试。商业SKU未知，不能替代客户商品。选段沿用先前实际回看后校正的范围，保留原人工依据；本轮没有重新运行视觉模型，不能据此声称自动识别准确率提升。

每类核对三个推荐，第一项只作为隔离技术示例方向，不记录客户真实风格确认：耳机为年轻学生/通勤、活泼利落；包装为重视细节、温柔克制。另保存单独变更人群、单独变更气质，以及共用中性brief只改商品文稿的结果。推荐“适合”属于编辑判断，最终仍需客户选择和看样。
