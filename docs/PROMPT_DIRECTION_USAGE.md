# 商品关键词与画面 Prompt · 品类扩展

在客户“商品制作”流程中，先填写/点击标签补充商品类别、目标人群、希望气质与片种，保存后确认事实和文稿，再选择三个方向之一。推荐卡显示主画面语言与命中词，选中后可展开对应Prompt、固定版本来源与素材要求。

本轮是既有流程的增量，不安装或执行任意外部Skill。生产时不抓网页、不调用大模型生成画面、不发送客户资料到新平台。已有火山配音的发送同意、试听、听核与版本流程保留。

| 主画面语言 | 八种匹配变体 | 实际画面处理 |
| --- | --- | --- |
| 商品局部急推 | 科技定点 / 活力商品 / 日常轻推 / 瓶身点题 / 食品表面 / 衣领走线 / 收纳焦点 / 工具接口 | 真实素材短促推向焦点、留看、回到整体，不变速不震屏 |
| 整体与细节同步双窗 | 理性结构 / 材质纹理 / 日常细节 / 瓶口 / 食品纹理 / 整件织纹 / 家居分区 / 工具刀头 | 同一素材、同一时刻，上窗整体、下窗焦点细节，不是前后效果比较 |
| 形状窗口展开 | 克制轮廓 / 温暖圆窗 / 活泼斜面 / 包装柔展 / 餐桌圆窗 / 衣物斜面 / 家居空间 / 工具轮廓 | 真实画面在窗口中展开，底层仍保留同帧，不生成产品几何或新角度 |

当前28张卡片，新增15张品类适配卡含镜头目的、具体画面编排和听读配合。它们仍映射到三类已实现的媒体动效，不等于新增24种渲染效果。旧9张内容与digest保持不变。

三个既有风格家族分别分配不同主画面语言；商品、类别、人群、气质和片种目的按固定词表加权选择各语言中的变体。相同输入稳定，不保证任意改一个词都更换全部ID；商品语义不是商品真伪、性能或适配度证明。参考库的其他特效尚未接成可执行配方。

新计划的安全非动作镜延续各自的主语言，默认重复最多两次；动作句和收尾保持完整留看。实际已有动作保护区间会进一步延后或关闭动效：急推包含回位，双窗包含末尾回收，形状展开在等待期和完成后恢复完整清楚原画面。

素材短边不足720px或镜长不足时保留基础编排并提示；数字阈值不代表清晰度已获人工认可。横屏完整显示仍可能偏小，可逐镜选择方形取景并调焦点，必须核对手、商品及全过程。没有素材不会凭Prompt虚构商品操作。

分镜中可选择“商品画面Prompt”、更换或清空，两个相关选择器会同步。保存当前镜头或创建单镜新版本；其余镜头保持原决策。全局样式、声音时长或渲染引擎升级不属于“只改一镜”保证范围。旧分镜没有prompt_card时不会自动套入新动效。

每镜manifest/SHOTBOOK记录实际Prompt ID、内容摘要、来源/许可/commit、卡片digest、匹配词、实际执行配方与避让结果。卡片文本是制作说明，仅映射到有限枚举和数字参数，不执行自然语言或外部代码。新卡片以后应使用新版本ID，旧卡保留。

来源是项目已保存的Shotcraft急推参考（Apache-2.0，43bd349a…）和Huashu photo-led方法（MIT，3e927801…）。新实现位于MediaMotion.tsx，未复制上游品牌、演示素材、模型或字体；具体路径/URL/SHA见 `docs/evidence/prompt-direction/sources.json`。

本机耳机实拍对照入口：`/samples#promptExamples`；滴管瓶包装三方案：`/samples#promptCategoryExamples`（约19秒，沿用对应商品的既有配音，不加静帧凑时长）。三个完整版本共用原文稿、原声音和实拍区间，但风格和音效混音可以不同。每个版本另附只修改首镜同类Prompt的副本；依然待人工听核、审片，不自动投放。

隔离复跑：

```sh
.venv/bin/python scripts/build_prompt_samples.py --source /绝对路径/job.json --runtime /原资产根目录 --data /全新的外部验收目录
.venv/bin/python scripts/check_prompt_samples.py --data /该验收目录
.venv/bin/pytest -q tests/test_prompt_direction.py
npm run check --prefix render/remotion
```

构建脚本只读取冻结源和资产，拒绝现有输出或仓库内输出，不创建客户确认。测试中的确认是临时fixture；实际人工听审不能由这些记录代签。

新增品类卡只是取景和讲述方法：食品外观不能证明配方或口感；服装织纹不能证明成分；家居分区不能证明容量/承重；工具刀头不能证明性能；美妆包装不能证明功效。当前这四个新增品类只完成匹配/契约测试，滴管瓶完成三条实际渲染，不能把词表覆盖当作实拍验收覆盖。

只换Prompt的对照必须改变执行参数并检查首镜解码画面；不能只凭卡片名称或MP4文件SHA不同认定画面不同。首轮等参数对照保留为未发布试跑，最终样片使用经核对的不同参数。

完整Shotcraft参考库已收录124卡正文和150变体/样例链接，入口`/prompts`；9来源卡有限适配，115待适配。新增4张项目Prompt卡对应字形商品开场、同帧分区解释；强冲击/字形/分屏气质明确要求时参与新推荐。普通气质继续旧三类主语言，旧板不重编排。详见完整库说明（历史记录或本机文件，未随公开版分发）。
