# 0.17.0 文字表现、Prompt 自选与发布验收

日期：2026-10-22。沿用 Apple Silicon M2 / 8GiB 本机。现有 UI、逐镜修改、模型策略及全部人工确认保留；未新增云调用、配音收费请求或平台写入。

## 实现范围

- 三种有限文字表现：关键词重拍、分词揭示、大小字对照。字卡和着重词必须摘自已确认原句。本机字体测量，明确可靠字锚点、句级回退和无声编排三种依据。
- 完整动作及保护区间关闭文字运动，视频速度、镜长、字幕和配音不改写。旧任务未设置新字段时沿用原版表现。
- 参考库可自主选择项目、句子及已有本机变体，生成按商品/人群/气质/原句的规则适配说明。只带入编辑草稿，不自动保存、生成或审核。
- 选择绑定项目、任务、项目修订与分镜修订。返回后发生变更则拒绝旧选择；高清素材不足或参考未适配时不提供执行入口。
- README 增加两张原创界面示意、三个本机实际渲染的效果帧与动态预览。界面图明确标记非浏览器截图；无客户素材或上游样例品牌资产。

独立代码检查发现的返回链接参数丢失、默认误选第一镜、字形遮罩被清空、文字整体越界/缩放裁字、改稿保留失效关键词等问题均已修复，并补相应初始化、SSR和布局回归。

## 已实测

| 项目 | 结果 |
|---|---|
| 六镜实拍回归 | 从已有隔离夹具复制已授权藏蓝素材和声音，在全新目录真实渲染27.8秒，最终冻结代码154.08秒；仅首镜 impact→reveal 后23.39秒（与其他测试并行，非严格性能基准） |
| 单镜稳定性 | 第二遍1镜重渲、5镜命中缓存；其余五镜视频逐字节一致、整片解码PCM一致、SRT一致；严格完整解码通过 |
| 动作与声音 | 泼水镜依据保护区间关闭文字运动；可靠锚点驱动标题，估算字/缺少锚点回退稳定标题，不伪造字级时间 |
| 原版兼容 | 新字段默认空；比较规范化忽略空字段；新样式开关、回退到原版、实际修订与影响预告一致；旧审批不转给新片 |
| 页面事件 | 真实HTML与JS在测试专用 LinkeDOM 中通过项目/镜头选择、返回草稿、来源字面显示、清空与旧响应隔离；没有业务写请求或审批操作 |

工程回归全部为 `AUTOMATED FIXTURE`，没有新增客户听核或成片认可。27.8秒工程稿不是此前客户确认的29.1秒新版；正式成片与审批保持不变。

最终干净副本：949 passed / 4 skipped / 1 deselected，332.15秒；Node 38项、TypeScript、Ruff及DOM事件通过。Mac源码客户包253文件逐一校验，新安装副本实际渲染1080×1920、120帧并完整解码。

## 限制和回退

- 未使用 Computer Use、浏览器截图或真实窗口像素验收；DOM/样式检查不等于跨屏幕视觉验收。新样片仍须实际听审。
- 源片预览不显示尚未渲染的文字效果；当前生成成片后才是最终动效。卡片索引数量不等于全部模板可执行。
- 最终安装副本通过0.16.0和0.13.1旧校验器，实际启动后验证页面、第三镜Prompt上下文、已审导出及全部原审批不变。
- 0.17.0 无新数据库迁移（schema14）。首次运行新引擎会刷新镜头缓存，不承诺复用0.16.0渲染缓存。
- 单镜样式可选“保留原版”；已保存版本可比较/恢复。升级前备份，软件回退关闭新版后从0.16.0原应用及对应数据副本启动；不把带新字段的数据库交给旧版写入。
