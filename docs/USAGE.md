# 使用与排错

## 让第一条成片可用

用短脚本开始，每行一个明确画面。比如“展示杯身外观”“查看杯口细节”。素材按行顺序分配，画面数量不足会循环。P0 没有语义搜镜头或自动 B-roll：你上传的顺序就是剪辑顺序。横图和横屏视频按比例完整显示并留边，不自动裁掉商品。

有配音时，总时长跟随配音，并按每行字数分配镜头，每镜至少 1 秒。没有配音时使用每镜时长，并输出静音音轨。字幕 SRT 与烧录字幕采用同一镜头时间轴，但没有进行语音识别对齐。需要精确口播同步时，先在上游处理配音/分段，或等待未来强制对齐适配器。

点击生成会保存页面尚未保存的脚本修改，再锁定内容。生成后想改字或替换素材，使用“复制为新草稿”。页面会保留原任务、素材、报告及人工复核记录。

## 内容预检

rules.json 是有限示例词表，有版本号。检测到根治、绝对安全等阻断词时停止渲染，保留报告。绝对化/效果/促销用词提示人工核验。没有命中也会进入人工复核；不自动替换词语。

未自动覆盖：画面、画面中的文字、配音内容、音乐版权、肖像授权、商品资质、实际价格/销量、平台最新规则。检查清单是必要人工工作，不能因为有 QC 报告就跳过。QC 仅证明编码、尺寸、时长、音轨和完整解码等技术检查通过。

## 常见问题

- **渲染进程离线**：通过 scripts/start 启动整个工作流，或独立执行 `python -m ecom_video.worker --data var`。只开 API 不会执行队列。
- **会话已更新**：API 重启更换写入令牌，刷新页面再试。已保存数据不丢失，未保存文本请先复制。
- **字体缺失/字形异常**：设置 ECOM_FONT 为覆盖中文和所需字符的 TTF/TTC/OTF 字体。P0 不支持自动字体下载和逐字符字体回退。
- **媒体无法解析**：确认后缀与内容一致，重新导出标准 PNG/JPG/MP4/WAV。播放列表、SVG、动图、网络链接不支持。
- **配音太短**：配音时长不能小于脚本镜头数（每镜至少一秒），请减少镜头或换配音。
- **生成失败**：页面显示原因。检查 FFmpeg 的 libx264 编码器、中文字体、磁盘空间和素材完整性；剩余次数允许重试。
- **重启后显示正在合成**：旧租约最多 45 秒到期，运行 worker 后自动重排。不要直接改数据库状态。
- **找不到文件**：文件被外部移动/删除；恢复完整数据备份或新建任务上传。
- **字幕挡住商品**：首版字幕位于下半部安全区域，长句请拆镜；目前没有自由拖动字幕的时间线编辑器。

不支持公网、多用户、云端同步、账号登录、自动投放、产品链接、产品文档、AI 写脚本、TTS、背景音乐混音、语义搜镜头、自动学习或无人工参与的内容放行。这些不是隐藏开关。

## P1 产品资料与脚本

工作台顶部“产品资料 → 脚本”进入资料夹。先上传/读取资料，再选择事实并填写确认记录；之后生成脚本、保存改写新版本，第二次确认后才创建下方剪辑任务。旧手写脚本流程仍从“已有脚本 → 剪辑”进入。

| 情况 | 处理方式 |
|---|---|
| PDF 没有文字 | 扫描件不做 OCR；先准备文字版文档 |
| 资料没有短句候选 | 展开完整原文，选择页码/段落，复制连续 1–100 字加入候选 |
| 产品链接被拒绝 | 检查为公开 HTTPS/443；登录、验证码、动态页面改用文档 |
| 域名包含非公网地址 | 本机 DNS 可能返回 fake-IP、内网或回环地址；使用公网 DNS 解析正常的网络或上传文件。程序不接受代理返回地址，也不绕过检查 |
| 勾选变化后生成按钮不可用 | 重新确认事实，或恢复上次确认的勾选 |
| 资料已更新（409） | 点击“重新载入”，检查新的修订后再操作；未保存分镜会提示后才丢弃 |
| 产品剪辑脚本不可编辑 | 打开“产品脚本的事实来源与确认记录”，回资料夹修改并确认新版本 |
| 模型选项不可选 | 在启动服务的 shell 配置三个 ECOM_LLM_* 变量并重启，或直接使用本地编排 |
| 模型失败 / 格式不符合 | 不生成脚本；检查服务兼容性、网络和配置后重试，或手动选择本地编排 |
| 原始资料缺失/变化 | 停止使用此任务，恢复原件或新建资料夹；不要改数据库绕过哈希检查 |

语义核验由人工完成。检查事实原文里的型号、时间、规格、否定条件与适用范围；不同资料冲突时不要直接同时确认。截图文字、商品图片和音频不作为自动事实来源。`examples/product-demo.txt` 只用于测试，不能用作真实商品说明。
