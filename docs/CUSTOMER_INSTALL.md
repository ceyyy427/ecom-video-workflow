# 客户首次安装与交付

当前交付0.16.0：本轮验证macOS Apple Silicon（本机M2/8GiB），M系列同架构为目标；不把一台M2实测扩张为所有型号已验证。Windows入口暂保留，待客户Windows电脑另行验收。软件为本机源码客户版，首次需联网安装依赖和配置模型；不是已签名/公证的独立.app或全离线包。

适用：macOS本机单用户受控试用。Windows提供启动入口，但仍需实际机器验收，不按macOS结果承诺兼容。不要将本服务直接暴露到公网。

## 日常推荐：双击启动，无需输入命令

1. 将安装包解压到可写的新目录，双击根目录的 **启动剪序.command**。macOS 如提示来源未知，先核对交付来源，按系统提供的“打开”流程处理；不要关闭系统安全保护。
2. 首次自动安装锁定的项目依赖，终端窗口显示进度，不用输入命令。之后打开 `/setup`“开始使用”页面。基础 Python、uv、Node.js 22/24、FFmpeg 与中文字体仍需预装；缺项会显示浏览器帮助和本指南，不会自行安装系统工具。
3. 页面选择本机 Ollama 模型并验证图片能力；没有模型时，先在 Ollama 安装本机视觉模型或使用手动选段。勾选下载说明后，页面可安装/校验固定官方来源的 FireRed 字幕模型，也可取消。模型未完整校验前不启用；安装期间请不要关闭启动窗口。已有损坏目录保留，由你在 Finder 移走后再安装。
4. 页面密码框输入语音 Key，可选音色；保存到 `~/.config/ecom-video/volc-voice.json`，权限600。不回显、不写浏览器本地存储、不随业务备份携带，也不自动验证收费权限。已有配置需明确勾选替换。启动环境变量有优先权时页面禁用保存，避免看似换 Key 实际未生效。
5. 从页面进入商品制作。事实、文稿、风格、听核与成片审核继续由客户确认。配音合成前仍需另外同意文稿发送与计费。双击启动始终使用客户模式，平台写入关闭。
6. 同安装目录重复双击只打开现有客户实例；其他程序占用8765时停止启动并提示，不会关闭别人的程序。首次安装中重复启动会提示等待。
7. 先保存编辑并等任务停止，再在启动窗口按 Ctrl-C 退出；不要直接强制结束进程。关闭页面不会停止服务。

日常可从“商品制作”“操作指南”顶部的“首次配置”回到此页。高级安装、恢复与故障命令保留如下；Windows仅保留原高级入口，本轮双击启动只在macOS验证。

## 1. 解压到全新目录

使用交付方提供的ZIP及SHA256，先核对校验值，再解压到新目录。不要覆盖原项目或旧数据。包中`PACKAGE.json`记录每个文件的SHA256；不包含数据库、客户素材、密钥、模型、系统字体或已有依赖。

安装需要网络下载锁定Python/npm依赖及渲染浏览器；后续示例用本机模型，不发送素材到云端。
先自行安装Python3.11+、uv、Node.js（建议22或24）、FFmpeg/ffprobe、中文字体。不要修改全局安全策略或关闭TLS验证。

```sh
cd "/你的目录/剪序客户版"
python3 scripts/install_customer.py
```

安装脚本执行`uv sync --locked`、Remotion目录`npm ci`、检查/准备渲染浏览器，再跑环境自检；失败时按终端对应步骤修复后重试。未启动服务，也未创建商品或配置Key。软件依赖与浏览器下载的网络、权限问题不等于商品资料错误。

## 2. 配置本机模型

语音对齐：可由交付方提供与`docs/P5_MODEL.json`一致的本机模型目录，显式校验导入：

```sh
.venv/bin/python -m ecom_video.customer_setup models --asr-from "/本机已下载模型/firered"
```

没有该目录时运行`.venv/bin/python scripts/setup_p5.py`按固定SHA256下载公开模型；网络失败不跳过校验。模型约740MiB，另留下载临时空间。

自动识别：安装并启动Ollama，先显式`ollama pull qwen3-vl:2b`；或使用已经安装且可核验的本机视觉模型，然后：

```sh
.venv/bin/python -m ecom_video.customer_setup models --vision-model "qwen3-vl:2b"
.venv/bin/python scripts/vision_setup.py
.venv/bin/python -m ecom_video.maintenance check --data var
```

视觉配置只访问本机Ollama标签和能力信息，拒绝cloud/远程代理，不自动下载或推理；示例运行会另做实际推理。模型文件存在不等于识别正确。缺视觉模型可以人工选段。模型路径目前是本安装目录`var/models`，业务`--data`不会自动搬迁模型。

配音可上传现成音频；首次安装演练在macOS用本机Tingting声音，不需要Key。正式使用火山语音时，由客户在本机配置语音Key，重启后先试听，再人工听核；方舟大模型Key不是语音合成Key。本包不会替你开通、调用或测试收费资源。

在本机交互终端运行`.venv/bin/python scripts/volc_voice_setup.py`，隐藏输入Key并保存为私有配置；不接受命令参数/管道密钥，不发起调用。已有配置要明确加`--replace`，本包不替换你的凭据。`DOUBAO_TTS_API_KEY`环境变量优先于配置文件，修改后从已更新环境的终端重新启动服务。资源开通与只读检查见包内`docs/VOLC_VOICE_AUTHORIZATION.md`；其历史演示/开发验收链接不在客户安装包内。

## 3. 启动客户模式

```sh
.venv/bin/python -m ecom_video --customer --data var --port 8765
```

打开`http://127.0.0.1:8765/create`，从“操作指南”点本机检查。客户模式强制关闭平台写入和自动Agent执行，开启CSV冻结复盘与创意迭代；不需要制作者拥有投放账户。不带`--customer`的开发入口仍保留，交付时使用本命令。

新建商品→上传资料→人工确认事实→生成或粘贴文稿→确认文稿→选择三个推荐之一→上传/生成配音并逐句听核→素材缺口检查→分镜逐镜核对→生成→人工审片。不能通过安装脚本替客户完成这些确认。

极少量漏识字在高匹配时可生成局部估算时间，页面仍标为估算锚点，须逐句核对；估算不证明音频实际说出了该字。异稿、较大缺口或超出范围会停止对齐并保留识别诊断，不自动改写文稿或听核通过。

## 4. 明确标识的安装演练

在macOS且本机模型就绪后，使用**不存在的新目录**执行示例：

```sh
.venv/bin/python scripts/customer_smoke.py \
  --workspace "/你的目录/剪序首次验收" --simulate-confirmations
```

该开关仅供隔离技术验收：生成原创合成商品素材与本机配音，上传资料、生成稿件、模拟标记的事实/文稿/风格/听核，运行真实本机识别、对齐、渲染，最终停在待人工审片。不会提交成片审核或任何平台操作。没有该开关不执行，已存在的工作目录拒绝覆盖。
输出`acceptance.json`、实际成片和备份恢复证据。本演练不代表商品事实真实性、商业画质、真人听核或全新电脑兼容验收。

## 5. 停止、备份与恢复

Ctrl-C停止启动器；暂停/取消待执行任务并等待正在运行任务结束。不要删除DB或强行清除租约。

```sh
mkdir -p "$HOME/Documents/剪序备份"
.venv/bin/python -m ecom_video.maintenance backup --data var \
  --to "$HOME/Documents/剪序备份/首次交付"
.venv/bin/python -m ecom_video.maintenance verify \
  --bundle "$HOME/Documents/剪序备份/首次交付"
.venv/bin/python -m ecom_video.maintenance restore \
  --bundle "$HOME/Documents/剪序备份/首次交付" \
  --to "$HOME/Documents/剪序恢复演练"
```

目标必须不存在；恢复不覆盖旧数据、不启动服务、不批准任何任务。核对所有文件指纹、文稿版本、人工状态和冻结复盘后，再决定切换到恢复目录启动。模型、源码/依赖、未登记的资料清单和密钥不在业务备份内，须单独保留/配置；钥匙串授权迁移后可能需客户重新授权。

## 9. 商品画面精修

新建分镜会启用实测标题排版和可靠字锚点关键词轻强调；逐镜“画面精修”可切回原版。改一镜保存新版本，原片保留；事实、文稿、风格、听核和成片审核仍由你确认。关键词没有可靠识别时显示普通字幕，不自动改稿或替你通过听核。不同电脑字体不同，请在实际客户机看样。旧分镜默认原版；首次跨引擎重做可能重新渲染全部镜头，之后同版本逐镜缓存继续生效。

样片页的“Skill 方法 · 同商品画面精修”提供新旧对比。只读上游参考不参与客户运行，不安装上游云转录或受限模型；新功能不增加配音请求或平台写入。

## 10. 商品方向与节奏记录

三个推荐会显示实拍/字卡/观察式方向，新分镜按开场、铺陈、动作与收尾安排动效主次。换商品、人群或气质后重新计算，旧分镜不自动改变。分镜记录中的motion_treatment列出实际cue和估算阅读窗：镜内秒与全片秒分别标明；短窗口需要看样调整，不等于自动审美或合规放行。事实、文稿、风格、听核和成片审核继续由你确认。

## 11. Mac交付：从商品到成果包

1. 解压本次Mac ZIP到自己的可写目录，双击“启动剪序.command”，首次到“开始使用”配置。缺基础工具时按提示安装，不要关闭Gatekeeper或绕过TLS验证；来源提示按macOS提供的“仍要打开”流程处理。
2. 在“商品制作”填写片种、商品、人群与希望气质，上传资料和画面。视频原件≤512MiB，必要时自动转正并生成全高清工作副本≤100MiB；“素材接收与预检”显示技术结果、未知与缺口。原件保留不代表同款、动作或授权已通过。
3. 事实人工确认后比较三份联合方案，采用仅创建待确认稿。确认文稿、选择风格，再上传匹配配音或明确同意生成配音，逐句实际试听和听核。未配置语音Key时仍可上传现成声音；不需要投放账号。
4. 生成分镜、逐镜核对入点和动作，再生成成片。只改一镜用镜头下方按钮保存子版本；改稿、声音或时长需要重新确认/对齐。旧版本保留，不能把缓存复用当成画质签收。
5. 成片旁“准备当前版本待审包/交付包”，完成后点击ZIP下载。包中有成片、可用SRT与配音、文稿、分镜、来源哈希、辅助审核摘要和人工记录。状态缺失、输入变化或工程fixture只输出待审包，不自动审批或发布；旧任务字段缺失会保留待核。
6. 完整看听、处理审核报告，再填写成片审核人和意见。通过只绑定当前成片版本，新版不继承旧片签收。下载包外部SHA及包内HANDOFF.json供交接核对；导出动作本身不是投放/广告授权。
7. 交付包是成果，不含原片、数据库或可独立重做的工程。要迁移制作，请在“数据与版本”另建业务备份、校验并下载，恢复到独立新目录，原目录保留。已下载成果ZIP请单独保存，恢复后可从项目重新导出。

常见卡点：上传处理中请等单片结束再传下一份；“依据已变化”先保存编辑并刷新，重新比较方案；对齐提示异稿时使用对应原稿/配音，不自动改稿；某句缺动作时补拍或人工选段；文件SHA错误时恢复或重新生成，不继续交付损坏副本。未带历史样片的空安装会显示未包含素材，客户三条已签收作品另包提供。

## 0.17 文字表现与自主选择 Prompt

选中一镜后，可选择关键词重拍、分词揭示或大小字对照，着重词须摘自本镜字卡；“保留原版”可撤回新效果。源片预览不显示尚未渲染的动效，生成新版后实际看听。

“自主选择 Prompt”打开镜头参考库，选择商品、句子和已有本机变体，阅读按人群、气质及原稿生成的适配说明，再带回这一镜。只是未保存编辑，核对修改影响后保存，人工分镜确认、听核与成片审核继续保留。参考待适配卡不执行；分镜版本变化时重新选择。

先备份再升级，旧软件和数据副本保留。回退从对应旧数据启动，不把带新字段的数据库交给旧软件写入。
