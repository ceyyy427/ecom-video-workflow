# P9：更稳妥地按文稿选择实拍

进入 [客户商品制作](http://127.0.0.1:8765/create)，上传商品资料、图片、实拍视频及与文稿一致的成品配音。确认事实、文稿和配音对齐后，保持“自动选段”开启，选择推荐风格并生成分镜。

## 本轮改变

- 文稿明确提到桌面、书本、电脑等对象时，先核对候选关键帧的识别描述，再让模型排序。没有书本的杯盖特写不能仅因模型打分高而匹配“桌边与书本”。
- “笔记本电脑”不视为纸质笔记本；“未见书本”“书本未出现”“可能有书本”不能充当有书本的依据。
- 内容相关性优先于换镜头数量。同等相关的候选中优先使用实拍、未重复的时间段，并尽量为后面的具体场景保留唯一合适素材。
- 实拍默认使用“实拍全画幅”，完整保留原动作；可在每镜“编排”切换回图卡布局，画幅仍可选完整显示/铺满。
- 分镜下方的说明显示命中的画面要求、观察词、模型版本。匹配分是编辑评分，不是准确概率。

## 怎么人工调整

1. 查看分镜的文稿和素材候选关键帧，核对商品身份、背景和动作是否一致。
2. 在该镜的“识别片段”中选择其他候选，或更换素材、调整视频入点。人工选择不会被自动筛选器覆盖。
3. 保存或单独重做该镜；系统建立制作版本，其他镜头继续复用，原成片保留。只有未变化且缓存校验通过的镜头可以复用。
4. 如果提示“画面要求缺少明确识别依据”，先检查识别是否漏了对象；可以补拍/换素材，也可以关闭自动选段，按画面人工安排。不会悄悄换成不对应的图片凑满时长。

## 适用边界

这是一套有限的对象/场景词表和关键帧证据检查，不是通用语义裁判。当前覆盖桌面、书本、电脑、绿植、厨房、户外、包袋，以及杯子、杯盖、开口、把手、倒入动作线索。未覆盖的颜色、具体型号、空间关系、复杂否定和动作过程仍需要模型建议及人工核对。关键帧可能漏识；动作线索不等于全过程发生在所选秒数内，更不能证明功效或性能。

多件商品的素材应按商品分开建立项目。本次授权实拍演示明确包含不同杯型，用来检验两个场景的选择，不可冒充单一客户商品。
