# 三份备选文稿与逐句画面策略

## 操作

1. `/create` 上传资料、对应图片/视频和配音，核对事实；保存目标人群、片种与希望气质。
2. 文稿区点“预览三份备选稿”。预览不保存、不覆盖当前稿；明确“采用”才创建待确认草稿。资料/事实/brief更新后旧预览失效，请重新生成。采用后仍须人工确认文稿。
3. 确认文稿后推荐三个风格方向。新推荐策略5把主方向用于开场，再按每句内容混合画面；旧策略1–4保持原编排，不自动升级。
4. 配音试听、逐句听核后准备分镜。检查每镜的来源、选段、焦点、保护区间和选卡理由；可换卡、关卡、调整选段与焦点。没有素材和事实依据时先补齐。
5. 生成待审成片。只改一镜建立新版，旧版保留；重新检查修改镜及相邻过渡，再人工审核成片。不会自动投放。

## 支持与边界

| 内容 | 策略 | 需要人工核对 |
|---|---|---|
| 商品细节 | 真实画面连续、焦点四角短程合拢并落定 | 焦点是否真在商品部位；是装饰框，不是检测结果 |
| 数字/参数 | 完整原文信息行、静态数值，无凭空趋势 | 对应当前句完整引用已确认事实；不截掉条件/单位/口径 |
| 销售句 | 同上，不能补造优惠、有效期或转化结论 | 来源、价格适用范围和时效；本轮没有真实销售素材样片 |
| 文本说明 | 完整短句按人声接力，长句退回普通字幕 | 不把否定、条件截成肯定卖点 |
| 图片 | 选择对应授权图，有界运镜 | 无图提示缺口，不用视频候选冒充图片已就绪 |
| 商品视频/场景 | 主方向画面+媒体层前景交接，每片最多一次 | 不伪造新场景/多机位；字幕和人声不随遮罩切掉 |
| 操作动作/收尾 | 连续原速实拍，动作默认关闭强调动效 | 关键词不是动作识别证据；需回看选段与保护区间 |

数据/销售句缺少逐句完整引用，或完整原文超过48字时，不启用强调卡，保留原稿字幕并提示。超过48字需人工保留全部适用条件拆句、重新确认。数字标题关闭，避免大字“39元”遗漏其后限定。手动选卡也执行相同守卫。高清/镜长不足、事件窗口无法安全容纳时退回基础画面。

本轮三份备选是**本机有限叙事编排**：以已确认完整事实重排整体/细节/场景顺序，附素材策略，不是新增云端自由改写模型，也不承诺每份事实较少时主体完全不同。原有模型生成入口保留原配置和人工确认。

新增来源3卡（固定43bd349a… / Apache-2.0）：scan-bracket-sweep、row-embed、transition-hidden-cut。累计15/124来源卡有限适配、109卡仅参考；38张版本化项目Prompt，原34张不变。原卡针对界面/数据等场景；本项目仅学习合拢/落位/遮挡节奏，不搬检测、数字增长、虚构3D或上游品牌画面。
