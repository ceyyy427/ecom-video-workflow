# 标杆片与通用创意扩展

本轮先完成用户选定的藏蓝标杆片，同时建立通用内容的参考检索和独立本机配音接入。下面区分已实现、实测与后续工作，不能将上游项目的宣传能力视为剪序已具备的能力。

## 本轮入口

- 客户工作台 `/create`：逐镜“成片画面”可选“客户成片 · 原画与简洁字幕”。不覆盖历史样式；新选择仍走影响预告、保存、风格确认、渲染及审核。
- 客户画面隐藏默认工程标题、镜号、进度线和整幅暗色遮罩；保留已选字卡、部位标注、转场、必要画面限定和关键词字幕。复用已有动效执行器及动作保护。无声音/动作计划的旧动效须先补齐计划，或保留历史样式，不能悄悄丢弃效果。短语分页只使用可靠边界，长句和不确定边界沿用原分页、白色字幕，不伪造时间。
- 商品名称以已确认的 SKU 为保护词，尽量在词前换行，不把名称与型号后缀拆开；不删减原句条件或改写口播。
- 配音方式可选原有火山引擎或独立 VoiceStudio，上传配音继续可用。本机入口不会自动退回收费服务。首句试听不替代整稿和听核，换声保留历史。
- 通用内容 `/ideas`：输入想法、受众、气质及素材模式；从59套固定来源资料中检索六个不同方向，也可自己指定风格。支持查看适配Prompt和下载待确认方案。
- `/ideas` 当前是**参考检索与创作交接单**，不是59套已验证渲染模板，也没有自动完成六条动态预览或通用长片生成。原商品三套联合方案和既有渲染流程不变。

## 本机配音边界

上游 VoiceStudio 应用是 AGPL-3.0；下载的模型、分词器和声音另有许可。本轮不复制其应用代码进剪序，不将独立进程解释为自动豁免许可义务。

- 默认 OmniVoice 权重含非商业限制，不用作客户商用配音默认项。
- Supertonic 3 当前公开31语言表不含中文，不作为本轮中文替代方案。
- 首批仅开放 Apple Silicon 的 `mlx-audio` 引擎、`mlx-community/Kokoro-82M-bf16`（revision `a71e4d38b236d968966a2002c4c895dbd12b1c3c`）和预置中文女声 `zf_xiaobei`。
- 原生 VoiceStudio 的状态可能来自当前偏好，生成却复用旧缓存实例。因此不能只看模型名称；本轮要求专用启动器暴露 `/ecom/voice-contract`，在生成时核对实际后端。未提供这项契约的原生服务显示已连接但不可合成，不擅自替换模型。
- 独立服务默认 `http://127.0.0.1:3900`；可在启动剪序前设置 `ECOM_VOICESTUDIO_URL`，只接受同样格式的数字loopback端口。需要认证时仅在本机设置 `ECOM_VOICESTUDIO_API_KEY`。页面不接收或显示密钥。
- 请求为 `/v1/audio/speech`，显式中文、WAV、固定预置音色及0.8–1.2语速；不提供克隆操作。请求和响应绑定模型及revision，声音历史也保存该身份。限制状态流、音频大小与90秒时长，不跟随重定向、不读HTTP代理、不自动重试。
- 页面勾选前须在独立应用核对模型下载、许可、本机生成及未配置远程worker。连接成功、依赖安装成功都不等于真实中文声音已验收。
- 本机合成与视觉识别/渲染共用已有计算租约。声音保存复用已有版本表、文稿哈希和人工听核机制，无数据库迁移。

实际验证：官方 `v0.5.6` 应用资源和锁文件在独立目录安装；补齐官方要求的 `misaki[zh]==0.9.4`。模型112个文件通过哈希核对。真实中文工程稿生成7.85秒、24kHz单声道WAV；首次成功请求37.907秒（包含AudioSeal水印模型首次下载），就绪后同稿2.549秒。本机ASR识别出相应中文，有“本机→本集”的同音字差异；这些检查不替代人工听核，未替换客户主片声音。

独立环境约1.8GB，Kokoro缓存约380MB；上游首次水印模型另约56MB。本轮没有将整个VoiceStudio、模型和依赖塞入Mac安装包。需要独立应用环境的启动方式见[本机配音配置](VOICESTUDIO_LOCAL.md)。

## 通用内容的下一阶段

1. **六种可执行预览**：从59套资料中先选择六套适合“科普/观点/数据说明/图文故事/产品介绍/素材剪辑”的结构；每套都有实际6–8秒预览、素材条件、来源版本和退回策略。采用后只创建待确认文稿与分镜。
2. **通用创作协议**：`ContentBrief` 记录想法、内容类型、依据、素材、受众、气质、时长；`StoryWorld` 固定人物/物件ID、外观、色板、字体和场景。`CreativePlan` 带六方案与来源；继续落到既有SHOTBOOK和声音时间轴。
3. **代码画面执行**：无素材时用已验证的SVG/Canvas/React图形、图示与排版模板；生成代码必须固定来源、检查资源和确定性，并在受控目录渲染。不将用户Prompt作为shell、Python或任意网络脚本执行，不伪装实拍或凭空生成事实数据。
4. **声音验收与交付**：本机声音与现有配音作人工听感对比，补齐无需终端的安装/启动，再更新Mac包；不能以本轮工程合成通过宣称与收费服务同等音质。

通用事实类内容须保留来源与人工核对；虚构故事明确标识创作设定。角色一致性需要每镜遵守同一设定及人工回看，不能仅靠相同关键词宣称已保证。

## n8n 可选样例

`examples/n8n/ideas-manual.json` 是关闭激活状态的三节点样例：手动启动→读取本机会话→比较六方案。无审批、声音合成、渲染或平台写入节点。默认剪序端口8790，可修改为实际端口。

本机安装n8n时使用loopback可直接运行；Docker中的127.0.0.1指容器自身，该样例不能不经配置直接使用。本轮仅检查样例结构及真实剪序HTTP契约，未宣称n8n导入/执行通过。会话令牌只用于本机连接，不导出到公共实例。

n8n 的 Sustainable Use License 有使用/分发范围限制，不能笼统视为MIT式自由打包依赖。本轮不把服务器装进Mac交付包。它可帮助串联任务；没有同素材实测依据证明它会加速视觉推理或渲染。

## 回滚

客户画面逐镜选择“保留历史样式”，或恢复原制作版本；旧文件和已确认声音仍保留。配音选择火山/上传，即不依赖VoiceStudio；停止独立服务不会导致客户工作台无法启动。

`/ideas` 和新API为独立入口，没有修改旧商品文稿、事实或审批。移除实验入口无需迁移数据库。本轮没有发布新版Mac安装包，也没有公开客户素材。
