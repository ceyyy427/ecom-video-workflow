## 0.15.0 · 交付升级三期（Mac Apple Silicon）
本节替代上方0.14.0操作说明；历史证据仍属于历史版本。本次仅交付Mac，Windows需另机验收。

1. 完整解压发行ZIP，双击“启动剪序.command”；首次下载依赖需要网络。已有安装用户先在“数据与版本”备份，再登记可信ZIP与交付方提供的SHA，准备独立副本，人工启动。不要覆盖旧安装或旧数据目录。
2. 在“首次配置”检查FFmpeg、本机模型和配音。Key只在本机输入；不随安装包或备份发送。本机配音/识别优先；火山试听与生成按账号计费，须自行操作。
3. 上传资料与授权素材，确认事实、SKU和配色。选择商品、人群、气质，比较三套联合创意，播放6秒无声预览后显式采用；仍需确认文稿，预览不代表听核。
4. 生成/上传配音并逐句听核；核对稿件对应、型号读音、停顿和估算字时间。确认方向及最终分镜风格后生成。
5. 单镜编辑点击保存时先看“影响范围”，再点击“按此范围保存修改”。画面修改保持镜长、声音、字幕；改变动作边界可能涉及邻镜，必须整体调整。改文稿、声音或全局风格可能影响全片，不保证只重渲一镜。
6. 播放完整成片后逐镜审核：填实际审核人、问题类型、意见，并勾选实际看听。首条意见启用本版逐镜门禁；任何待检查或需修改镜头都会阻止最终放行。旧任务未启用时仍可用旧整片审核流程。新制作版本不继承旧逐镜结论。
7. 需修改时保留意见后创建新版本；逐镜通过后仍要完整听看并确认成片。工程模拟记录永远不算客户签收。导出页会明确标为“待审包”或“已完成当前版本记录”。
8. 在版本列表点“与当前版对比”可并排播放，查看镜头/文稿/声音配置差异。恢复历史版需填写操作人并确认；只恢复活动版本，全部版本、原片及审批保留。若事实、文稿、配音或素材已变，系统拒绝恢复；仍可打开旧版审阅，新制作从当前输入重新准备。
9. 客户自行投放。在“投放复盘”导入账户×素材×日报表，绑定具体成片版本，核对币种、归因口径与缺失数据，冻结快照。在商品工作台点“查看本商品冻结复盘与迭代”进入假设页，人工选择变更并准备新版；新版重新听核、风格确认与审片。再导入下一轮数据，冻结并比较。指标差值是描述性观察，不代表动效造成转化变化。
10. 交付包留存视频、字幕、来源与审核；另做业务备份用于继续修改。恢复必须选择全新目录，核对项目/声音/审核/冻结报表；模型和Key需要另行配置。回退使用旧安装与升级前的数据副本，新版数据保留，禁止把旧代码直接覆盖新版目录。

三期验收：□ 两品类修改对比 □ 逐镜退回门禁 □ 全部人工关口 □ 父片/快照/假设/新版关联 □ 备份恢复 □ Mac独立安装与升级 □ 客户实际听审。没有实际听审就留空最后一项。

## 0.16.0 工作台日常操作



1. **商品资料与素材**：新建商品，填片种、目标人群、希望气质。上传资料、图片、实拍；可选上传配音和音乐。单款/单色制作填写SKU与配色，并核对每段素材的身份声明。
2. **事实和文稿**：逐条核对资料后确认事实；选择备选稿或粘贴自己的稿件。表达可更口语化，商品事实须有依据。确认本版文稿。
3. **方向与声音**：比较三套推荐的讲法、素材支持和缺口，选方向；试听配音，满意后记录听核。换声音或改稿会需要重新对齐与听核。
4. **分镜和生成**：核对镜头与文稿，确认最终分镜风格，生成成片。完整动作保留起止与收尾；素材不足时按缺口提示补拍或手动调整。
5. **审核与导出**：逐镜检查商品、动作、字幕、声音，再完整看听。审核通过后导出“已审包”；未完成时仍可导出“待审包”给内部讨论。

## 编辑界面怎么用

- 左边是项目素材，中间是预览，右边只编辑当前镜头；下方有画面、配音、音乐和字幕轨。
- 点击画面块或拖动播放头可定位。已有成片与源片预览可切换；源片不包含最终字卡、动效和混音。
- 默认显示常用项；动效、焦点、动作保护等放在“精细调整”。已有画面小字仍直接显示，避免漏看。
- 多段实拍和完整动作使用分段编辑；快捷入点滑杆不会裁断受保护动作。
- 想看全部步骤，点“展开全部步骤”。审核报告、版本比较和历史版本在可展开区域。

## 只改不满意的一镜

1. 选择镜头，调整画面、字卡或取景。
2. 查看修改影响预告，再保存或生成新版。声音、转场等影响范围以页面提示为准。
3. 在版本比较中核对新旧版本，实际听看片后再记录审批；旧版本保留。
4. 需要回到原版，展开“历史版本与恢复”，核对目标版本后恢复。恢复会留下操作记录，不删除新版。

## 备份、恢复和升级

- 在“备份恢复”页面先备份，下载备份ZIP并另存。成果包和业务备份用途不同，两者都要保存。
- 恢复使用全新目录，不覆盖已有数据。恢复后检查商品、素材、声音、版本和审核记录，再启动该目录。
- 升级先备份，再上传新软件包并核对SHA；页面准备独立新版。停止旧窗口后，从新版目录启动。
- 回退时关闭新版，回到旧应用/旧数据副本。不要把两边数据库相互覆盖或手工拼接。

## 导出后与数据复盘

成果包包括成片、可用字幕/配音、文稿、分镜、来源与审核记录；原片、模型及Key不在成果包。

客户自行在平台投放。之后导入报表，核对账户、素材、日期及指标口径，再冻结快照；选择下一版假设后创建迭代版本。缺失数据继续显示缺失，不自动作因果结论。

## 常见问题

| 情况 | 处理 |
|---|---|
| 素材选不到或提示异款 | 核对SKU/配色、主体可见度、参照图与动作范围；不要为了生成跳过检查 |
| 配音与稿件不一致 | 查看识别内容和历史稿建议，使用对应原稿/声音；重新对齐后实际听核 |
| 字幕时间待核对 | 在逐字校正页核对估算锚点和停顿，不把估算当精准识别 |
| 改了参数预览还是旧片 | 参数尚未保存/渲染；“源片预览”也不等于最终成片 |
| 已生成但包仍待审 | 查看确认记录，完成当前版本缺少的听核、逐镜或整片审核 |
| 启动依赖下载失败 | 保留启动窗口中的错误，检查网络与磁盘后重试；已有项目保留 |
