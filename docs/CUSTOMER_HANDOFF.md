# 剪序客户交付清单

入口：macOS 双击 `启动剪序.command`；Windows 双击 `启动剪序.cmd`。首次配置 `/setup` → 商品制作 `/create` → 逐镜编辑 `/studio` → 待审成片首页 → 数据复盘 `/distribution` → 数据与版本 `/maintenance`。

- [ ] 核对交付包版本/SHA、系统版本、依赖版本和许可范围；完整解压到本机目录。
- [ ] 一键启动后本机环境检查通过，端口冲突不误杀别的服务。
- [ ] 视觉与ASR模型校验通过；配音只记录“已配置/未配置”，不记录Key。
- [ ] 原创技术示例制作完成，原片可播放；示例不是客户商品证据或客户签收。
- [ ] 客户商品素材/真实SKU及授权清单补齐，事实、文稿、风格由客户确认。
- [ ] 配音逐句听核，改一句后核对其他镜头/旧版本，完整审片并记录签收人。
- [ ] 内容审核报告逐项处理；缺少OCR/语音或素材证据时明确人工补检，不承诺自动合规。
- [ ] 页面备份通过校验，下载ZIP保存在独立设备；恢复新目录可重开项目、配音、审核记录和原片。
- [ ] 可信升级包先备份，准备独立新版，人工启动并核对；原安装保留供回退。
- [ ] 客户自行投放，导入账户×素材×日报表，确认口径/缺失/素材版本后冻结；迭代比较只作描述性分析。

签收记录：版本____；包SHA____；操作系统/架构____；数据目录____；模型摘要____；示例任务____；备份ID____；恢复/升级副本____；人工确认人____；日期____。

边界：本包不含客户数据、模型、Key或依赖缓存；首次依赖/模型下载需要网络；本机模型和环境配置不随业务备份迁移。云配音仅在客户明确生成/试听时调用。真实商品最终画质、事实与授权需要客户素材和人工审核。

本次实际验收与剩余平台限制见仓库 `docs/CUSTOMER_FINAL_ACCEPTANCE.md`；交付方应附该记录。Windows未有真机证据前不得勾选Windows已通过或宣传双平台正式验收。

旧0.12.0客户另核对：先升级到随附0.12.1过渡副本，人工启动后再上传0.13.1正常包。完整步骤见恢复指南；不得直接修改ZIP清单绕过旧校验器。首次安装不需要过渡包。
