# P15：冻结投后复盘

P15 只处理已导入的账户×素材×日报表，不连接新账户、不发起模型调用、不自动投放、不作因果归因。P13/P14 制作和所有人工确认保留；P16 实验尚未实现。

## 启用与操作

启动进程增加 `ECOM_REVIEW_SNAPSHOTS_ENABLED=1`，例如：
```sh
ECOM_AGENT_ENABLED=1 ECOM_AGENT_EXECUTION_ENABLED=1 ECOM_REVIEW_SNAPSHOTS_ENABLED=1 .venv/bin/python -m ecom_video
```
`.env.example` 只是配置示例，不会自动加载。默认关闭时原看板照常使用。

1. 打开 `/distribution`，选择客户账户，导入标准 CSV 或使用已有只读同步；投放仍由客户完成。
2. 在原有“关联平台素材与成片”中，核对平台素材 ID 与本地已人工放行的成片。绑定校验产物文件及哈希；不能拿不同成片冒用旧 ID。
3. 选择日期、查看实时复盘，再到“冻结复盘”填写记录人并确认当前账户/范围，点击“冻结当前复盘”。仅选择日期或打开页面不会自动冻结。
4. 冻结区独立显示账户、日期、ID/哈希、指标、缺失素材日、成片版本/创意特征和原报表证据。修改上方实时筛选不会改写已经选中的冻结版本。
5. 下载“冻结 JSON”，或从历史列表选择最近 50 份；更早版本可输入完整复盘 ID 打开。原报表下载按该快照的批次 ID 查找，不会自动替换为最新报表。
6. 可在已关联成片下记录人工标签，须勾选核对并指定创意证据字段；旧快照不变。补报表、标签或绑定后，再次主动冻结生成新版。

人工标签的确认只是本机维护者的记录，不是平台或第三方核验。模型标签仅接受带模型名/版本的外部提交，始终标作自报且未核验；本阶段不会生成标签、调用模型、覆盖人工标签或据此宣布素材胜出。

## 缺失、口径与来源

- 每天选账户最新完整批次；较新批次整天替换较老批次，不把老素材行补入新批次，不重复累加。
- 素材集合为范围内观测素材与本账户已有绑定的并集，不代表平台全量库存。`reported` 为上报行；`not_reported` 为当天有别的素材行但该素材未上报；`covered_empty` 为已覆盖但无任何行；`missing_report` 为缺当天批次。
- 空白/未上报为 `null`，真实 0 保留为十进制字符串 `"0"`；分母 0 时比率未知。区间指标要求每天相应字段已知，已观测小计另存，不将小计冒充完整区间。素材区间同样不以未上报补零。
- 金额/指标保存十进制字符串，先合计原始字段再算比率，六位小数 HALF_EVEN；点击率/完播率存 0–1 比例，不是百分数字面值。支付 ROI=支付金额/花费，不是 ROI2 或利润率。
- 币种、时区来自本地账户契约；支付口径是导入契约声明，没有独立向平台验证。归因窗口未提供则未知；来源显式币种/时区/口径冲突或窗口互相冲突时，停算合并指标和素材日派生比率，保留原始字段与来源声明。未知窗口不支持比较结论。
- 创意特征只提取提交时的冻结稿件/分镜，关联 `job_id`、父版本、视频 SHA、提交 JSON SHA 和特征版本；不从后来编辑的分镜或文件名猜测。旧任务缺特征显示 unknown/unavailable。
- 冻结时校验所选原报表，保存原文件哈希及采用日期的规范化行哈希；文件不重复复制。视频只引用既有人工绑定与产物登记哈希，本次没有重新哈希视频。`verify` 是当前来源核对，不能改变历史快照；原报表丢失时 JSON 仍可重读/导出，下载或核对明确失败。
- 冻结事务最多 31 天、20,000 行、500 素材、15,500 素材日、8 MiB JSON、128 MiB 原报表校验；超限拒绝，不静默截断。遇到超限请缩小日期范围或使用较小数据集。

## API 契约

入口继承原 Host/Origin/session token 的本机安全边界；不要暴露到公网。读能力目录不要求启用，其余 P15 接口默认关闭返回 404。

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/api/reviews/capabilities` | 开关、严格输入 schema、预算与禁止能力 |
| POST | `/api/reviews/snapshots` | `request_id/account_id/start_date/end_date/actor`，成功 201 |
| GET | `/api/reviews/snapshots?account_id=...&limit=50` | 历史摘要，limit 1–100 |
| GET | `/api/reviews/snapshots/{id}` | 保存的原快照，不重新计算 |
| GET | `/api/reviews/snapshots/{id}/export` | 规范 JSON；ETag 为 snapshot 内容哈希，非整个导出信封哈希 |
| GET | `/api/reviews/snapshots/{id}/verify` | 当前原文件、规范化行及登记特征核对；不核对视频字节 |
| GET | `/api/reviews/snapshots/{id}/sources/{batch_id}` | 仅下载该快照所用、哈希有效的原报表 |
| GET | `/api/creative-features/{id}` | 登记特征与当前标签；与历史冻结标签独立 |
| POST | `/api/creative-features/{id}/labels` | 追加来源明确的标签；201；不改变旧记录 |

`request_id` 为 1–80 位字母/数字/下划线/短横线，首位字母或数字；相同请求与输入幂等返回原结果，异输入 409。账户/复盘/特征 ID 为 32 位小写十六进制。标签另需 `label_key(hook_type/visual_tone/product_category)`、`value`、`origin(human/model)`、`actor`、`evidence_field`、`confirmed`；人工必须 confirmed=true 且不填写模型信息，模型必须 confirmed=false 并填写 `model_name/model_version`。证据字段须已知；不存在字段的标签拒绝。

422 表示输入/容量不合规，409 表示幂等冲突/来源缺失或校验失败，404 表示未启用或记录不属于请求快照；500 为安全固定错误，不回传堆栈、凭据或任意报表元数据。

## 迁移与回滚

schema v10→v11 仅新增五张表/索引/不可变触发器，不回填旧任务，不改变制作、Agent 或平台状态。启动前停服务并用 SQLite backup 保留匹配的旧库，不能复制运行中 WAL 的单个 db 文件冒充完整备份。关闭 P15 环境开关、重启仍使用 v11 源码即可回原看板，数据保留；硬回退必须恢复匹配 v10 源码与整库备份，不能手改 user_version 或用旧源码直接打开 v11。

验收命令及结果见 P15_ACCEPTANCE.md（历史记录或本机文件，未随公开版分发）。
