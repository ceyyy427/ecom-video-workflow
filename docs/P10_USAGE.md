# P10：同款外观与动作配音对齐

## 客户素材流程

1. 打开 `/create`，新建客户项目，上传资料、图片、实拍视频。选一张主体清楚、只展示该款商品的图片作为**商品参照图**，保存制作要求。不同款商品应建立不同项目。新项目默认勾选“参照图仅用于核对，不自动放入成片”，以免校准照片替代实拍；若确实需要把这张图用于创意镜头，可以取消勾选，其他上传图片不受此项影响。
2. 开启“只自动使用外观与参照图一致的素材”。动作片开启“倒水、开盖、合盖对齐配音动作词”；纯展示没有配音，请关闭动作对齐。
3. 后台检测切点并抽样观察。内容识别区展示抽样图片、外观一致/疑似不同款/无法确认、液流或盖体变化的时间范围。疑似不同款、主体移出和不确定的采样位置切断可用区间；只有连续确认一致且唯一主体的区间进入自动推荐，不跨越未确认间隙；更换参照图或识别规则后需重新识别。
4. 核对事实和逐行文稿。上传成品配音，或按 火山配置指南（历史记录或本机文件，未随公开版分发） 在本机配置 API Key，再从页面主动合成配音。
5. 生成制作版本，逐句听核字级对齐，选择三个推荐风格中的一个，生成分镜。动作词必须有可靠的字级时间，不能靠插值时间自动锁动作。
6. 倒水词应落在连续抽样可见液流的范围；开盖/合盖的每个候选都必须比较相邻两帧，明确观察到盖体位移和手部操作；仅凭两张图的盖体状态标签变化不成立，不能推断遮挡中的动作。动作源段不能越界，多动作须保持顺序。分镜说明会列出配音词和画面动作的本镜时间范围。
7. 预览后调整不满意的镜头。候选菜单允许人工选用未通过自动核对的画面；这是明确的人工选择，需要重新检查款式、动作和配音。修改一镜生成新版，旧片保留。

## 自动选择不能确定时

先检查参照图主体、视频清晰度和遮挡；同一镜头混入多只同类商品时，先切开或补充单品镜头。动作太快、开盖过程在画外、只拍到已经开盖、水流不可见、文稿动作词不在对应画面时，补充素材、修改分句或使用人工选段。不要把不相关商品或静态图当作动作证据。

自动检查是**抽样外观与剪辑建议**，不鉴定品牌或 SKU，不能证明商品性能。外观相近的不同款、遮挡、小物体和反光仍可能误判，最终必须人工审片。目前动作词表集中在瓶/杯的倒入、开盖和合盖；其他商品动作不应解释为已完成精确对齐。

## 版本与运行

- 数据库沿用版本 8，设置和分析上下文保存在现有 JSON 字段。
- 分析绑定参照图 SHA256、源视频 SHA256、模型身份和规则版本。参照变化与运行中取消均不得发布过期结果。
- v4 仅允许从指定 v3 代码指纹、相同模型身份、同一媒体和参照哈希的已完成结果复用原始观察；旧动作事件全部丢弃，盖体变化重新调用模型复核。复制的抽帧文件校验路径与哈希，并记录来源分析 ID。其他版本或来源不匹配时完整重识别，旧结果保留。
- 模型判断外观和当前画面动作分开；动作主体必须与参照类别绑定，多个同类目标自动退回不确定。
- 真实模型验证和样片路径见 验收记录（历史记录或本机文件，未随公开版分发）。火山真实合成需要用户账号配置，协议模拟测试不等于在线验收。
- 平台投放仍由客户操作，制作流程不触发广告创建。
