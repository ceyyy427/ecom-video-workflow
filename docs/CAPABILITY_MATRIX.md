# 能力与限制

| 环节 | 当前能力 | 需要人工或后续验收 |
| --- | --- | --- |
| 商品与脚本 | 文档/公开链接提取、原文来源、备选稿、事实引用、版本 | 事实真实性、SKU、授权与营销表达 |
| 风格 | 商品/受众/目的/气质匹配三个方向，固定Prompt与参考索引 | 用户选择；参考索引不等于全部渲染模板 |
| 素材 | 本机内容识别、外观比较、可见区间、有限动作检查、重复与缺口提示 | 遮挡、复杂动作、同款与最终逐镜核对 |
| 声音 | 主动TTS、现成配音、字级对齐、试听、单句新版本 | 资源授权、术语/数字/插值时间与人工听核 |
| 成片 | 实拍选段、运镜、动效、转场、字幕与混音、单镜缓存及父子版本 | 内容解释力、视觉质量与人工审片 |
| Agent | 工具契约、CLI/API、状态机、有界执行、暂停/恢复/取消与审计事件 | 人工关口不代签，不是通用自主代理 |
| 复盘 | 账户×素材×日、CSV、缺失与口径、冻结、素材版本与创意假设 | 客户真实数据核验；不作因果归因、不自动投放 |
| 交付 | 双击启动、配置、自检、备份、新目录恢复与升级准备 | 客户机器和Windows真机须独立验收 |

默认用于本机单用户受控操作，不是公网多租户服务。没有真实客户验证的数据，不声称转化率、ROI或规模化生产效果。
