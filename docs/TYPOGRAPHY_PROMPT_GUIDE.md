# 文字表现与自主选择 Prompt（0.17.0）

## 让关键词更醒目

在商品制作工作台选中一镜，填写摘自本句的字卡（最多8字），再选“文字表现”：

| 样式 | 适合的内容 |
|---|---|
| 关键词重拍 | 开头钩子、某个需要记住的商品观察点；关键词轻微放大后落定 |
| 分词揭示 | 分两三个语义组依次出现，配合一句讲解的推进 |
| 大小字对照 | 短引导配合大关键词，突出一句话里的主次 |
| 保留原版 | 完全沿用既有文字效果 |

“着重词”必须取自本镜字卡。留空时按整张字卡处理，不自动改文稿或添加性能承诺。字幕仍按口语停顿显示，标题和字幕分层。

有可靠字锚点时跟随人声；缺少或含估算字时使用稳定的句级标题，不做伪精准逐字强调。纯商品展示、没有人声时采用明确的编排时间，不宣称语音识别。完整动作或动作保护区间关闭文字运动，原片时长与速度不变。

## 自己选 Prompt，再适配商品

1. 从一镜的“自主选择 Prompt”进入参考库，或打开 `/prompts` 选择项目。
2. 查找整体、局部、字形、商品登场等方法，查看用途与完整来源。
3. 选择要修改的句子，阅读按该商品、人群、气质及原句生成的适配说明。
4. 选择已有本机实现的变体，点“带入这一镜”。未适配的卡只供构思；缺少高清同款素材时先补素材。
5. 回工作台后只是未保存编辑。检查原片、焦点、动作、修改影响，再保存。项目或分镜已变更时会拒绝旧选择，重新打开即可。
6. 保存并重新核对分镜，生成新版后逐镜与整片看听。更换声音/稿件仍须重新听核；不会自动审核或投放。

参考库共有124张卡、150个风格/样例索引；并非124种效果全部可执行。选择卡片不会运行网页代码、抓取上游媒体或调用云模型。

## 修改、恢复与回退

只改文字或本镜 Prompt 使用既有逐镜版本流程；动作、声音和相邻转场影响以页面预告为准。旧版与审批记录保留，新片仍待审核。

撤回未保存修改可重新加载项目；已保存版本可用历史版本比较/恢复。软件回退先停止新版，再从升级前的应用与数据副本启动0.16.0，不把含新文字字段的数据库交给旧版写入。0.17.0 不升级数据库 schema（仍为14）。

当前主预览的“源片”用于选段，不展示未渲染的文字动效；生成新版后切到成片核对。不要将旧成片或风格静帧当作本次修改的最终预览。
