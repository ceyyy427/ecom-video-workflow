# 固定素材组的阶段性能测试

本机视觉推理曾在Apple M2 / 8GB上使用同一组五段许可实拍进行强制重推：

| 阶段 | 实际耗时 | 业务结果缓存 |
| --- | --- | --- |
| 较早的本机调度版本 | 29.77分钟 | 零命中，72次真实模型请求 |
| 独立进程/Flash Attention与宿主缓存管理版本 | 21.04分钟 | 零命中，72次真实模型请求 |

阶段历史对照耗时减少29.3%。保留原模型、抽帧、输入和同款/可见度/动作完整性规则，该固定组的可用区间及动作事件一致。不是任意商品的准确率认证，也不是不同机器的速度承诺；已有结果复用的秒级核验不能当作首次推理速度。

后续对可选MLX后端进行交错测试时，未取得稳定速度和选段质量优势，未替代默认Ollama路径。这体现后端采用标准是速度与质量共同达标，而非只看单次耗时。

公开版保留基准工具 `scripts/benchmark_material_cold.py`、`scripts/check_material_cold.py` 等；原始素材、模型、私有过程记录和成片不随仓库分发。新机器复现实验须自行准备有权使用的同组输入，并区分首次推理、推理缓存和成片缓存。
