# Shotcraft 动效时序与完整样片

2026-10-18，按用户批准的透明杯26/27/28秒设计实施。沿用 Remotion；本轮不下载新模型、不发起云调用、不操作投放。

## 商品制作中的操作

1. 在 `/create` 上传资料、商品实拍与声音，保存商品、人群、希望气质；核对事实和文稿，再人工选择三个推荐中的方向。
2. 制作要求中的“同类动效重复上限”可选1–4，默认2，只影响下一次自动准备分镜；手动选择不被后台改掉。
3. 分镜逐镜可选择动效、克制/适中/利落强度、视觉偏移（-0.5至1秒）和动作避让。视觉偏移不改声音、字幕或素材入点。
4. 保护区间使用**本镜秒数**，例如 `0.20-1.50; 2.10-2.80`，最多8段，不能超过镜头时长。页面校验通过才能保存。
5. 区间来源区分手动、本机分析建议、口播词提示。后两者均须播放核对，口播词提示不是动作识别证据。换素材/入点会清除过时的视觉区间。
6. 系统按实际动画持续时间避让；空间不足时自动保留静态字卡，记录请求配方、实际配方和原因。保护覆盖相邻入口/出口时，在新分镜统一改为直接切接。
7. 已生成成片的单镜修订保持相邻转场。若新保护区间会迫使相邻转场改变，明确拒绝并提示整体草稿调整，不暗改邻镜。
8. 保存单镜产生新版，旧版可对比；整版换声、单句换声仍走原听核流程。合成与字幕不能代替人工听核，成片需再次审核。

## 呈现原则与边界

- 克制质感：全幅实拍、宋体、较少图形动作；种草：大字和场景接力；解说：分章、焦点框、可见细节。
- 动效从已确认文稿摘取标题/语义短句，锁定原词锚点；不补造规格、价格、性能或测试结果。
- 实拍保持连续、持续可见；额外变焦只作用文字，不把实拍做成图片卡片逐块进场。图片素材仍支持原有运镜。
- 只有 `motion_plan.version=2` 使用新编排；旧分镜缺省为 `null`，旧渲染分支与产物保留，数据库仍schema14。
- 这是首批卡片的本地适配，不是上游全库或通用视频生成模型。参考原件、许可和固定提交见 `vendor/video-shotcraft/2026-10-motion/SOURCES.json`（Apache-2.0）。

## 完整样片与复跑

入口 `/samples#narrativeExamples`。同一透明杯系列26秒克制质感、27秒生活种草、28秒细节解说，各可展开此前版本与仅第三镜改强度/时机版；均待人工听审。

```sh
.venv/bin/pytest -q
.venv/bin/ruff check ecom_video tests scripts
npm --prefix render/remotion run check
.venv/bin/python scripts/check_shotcraft_ui.py
# 必须使用新的独立空目录；重复运行缓存验收不是冷缓存实验。
.venv/bin/python scripts/build_narrative_samples.py --data /tmp/ecom-narrative-new-run
.venv/bin/python scripts/publish_narrative_samples.py --data /tmp/ecom-narrative-new-run
# 已重启本机API并加载新路由后，仅做GET/HEAD检查。
.venv/bin/python scripts/check_narrative_samples.py
```

构建脚本只读原样片及授权原片，在独立目录重裁两处动作、复用原火山声音/字级时间，不发起TTS/ASR或写业务库；发布只复制已编辑作品和证据。原stock不新增公开下载。

回退：先备份新分镜和样片，恢复本轮源码并重启原API/render/analysis三个进程；无需数据库降级。旧程序不能编辑含新字段的分镜，旧成片仍可播放；停用新版gallery不删除历史文件。
