# 国内内容方案 · D1 操作指南

入口是原工作台的 `/ideas`「创意实验室」，布局与客户制作页保留。

1. 选择抖音或小红书，填写想法、商品、人群、气质和预计时长。商品展示、场景分享、细节讲解各提供两种视觉结构；优先目标会影响排序。
2. 填写完整事实及来源，上传获准使用的图片/实拍，或选择已有项目素材。勾选「使用该项目当前已确认事实」后，服务端只引用该项目事实及版本；表单中的其他事实不会覆盖它。项目版本变化须重新生成。
3. 生成六个七秒静音预览。展开卡片查看开头、全文、选段依据和声音建议；页面另有折叠的平台标题、正文和封面构图建议。
4. 比较后采用一个方向，进入**新的待确认客户项目**。所选文稿、配方和冻结素材保留；继续人工确认事实、文稿、风格/最终分镜、配音听核与成片。旧审批不继承，预览不代表成片审核。

未检查的素材只按描述弱匹配，页面明确待核；已知主体可见区间及完整动作不能被裁断。已有项目的单款/单色锁定会保留为制作约束，不将原素材的审核人自动记入新项目。绑定商品事实时，不可静默混入其他项目素材。

「缺完整画面」的方向可以查看图示预演，但不能直接采用；先补素材或改稿再生成。完全没有实拍时，可制作带“非实拍”标记的代码图示，不能作为真实外观或性能证据。长动作可能无法放进七秒预览，不能通过截断绕过检查。

D1 使用有界规则、来源原文和现有模板，**没有新增大模型或配音调用**。人物经历、性能、数值条件不自由改写。预计全片时长是编排目标，尚不是实测语音时间；客户可继续修改文稿，正式配音仍按声学对齐与听核处理。D2 才扩展运营 Agent 的完整制作执行图；既有客户制作功能继续可用。

## 开发接口

- `GET /api/operations/capabilities`：本机资源可用性、规则编排方式、人工关卡。
- `POST /api/operations/plans`：`{brief:SuiteBrief.v1, expected_project_revision?}`；返回原方案记录及 `plan.suite_plan:SuitePlan.v1`。
- 素材仍写入 `content_brief.materials[{origin,id,project_id?,source_in}]`，不接收任意本机路径。已有项目同时提供 `project_id`、`product_ref` 当前版本和 `expected_project_revision`。证据引用由服务端解析，不接受伪造审批。
- 读取、排队、取消/重试、采用继续使用 `/api/idea-plans/{id}`；原 `POST /api/idea-plans` 和 `ContentBrief` 24 秒 v1 不变。新页面选择「通用想法」即回到旧入口。
- 计划保存在既有 `idea_plans` JSON 内，无新增表/迁移。编排、平台文案或输入改变会生成新摘要及新计划 ID；相同输入/输出重入复用原记录。

SuitePlan 的简报引用指向同一冻结计划内的 `brief_record`。候选脚本文字存于原方案；人工工作流尚未创建的脚本/分镜引用保持空，不冒充已审批对象。

## 验收与回滚

运行 `scripts/accept_domestic_suite.py --help`。`--stage content` 需要仓库外全新目录、有效旧备份、两个不同品类的许可素材与请求清单；生成真实 MP4、逐帧接触表、待确认项目及 `acceptance.json`。不合成声音、不制造审批。详见 [验收记录](DOMESTIC_D1_ACCEPTANCE.md)。

设置 `ECOM_DOMESTIC_CONTENT=0` 后重启隔离服务即可关闭 D1 规划，旧入口、历史预览和项目继续可读；它与 D0 的 `ECOM_OPERATIONS_ENABLED` 读取桥接开关相互独立。不覆盖生产目录或降 schema。代码回退使用 D0 提交 `0dbe37f783b91ed3e2d680bd8eb133a3543a0fb1` 的独立检出；D1 草稿数据保留在独立目录。
