# 素材检查与自动选段

进入“商品制作”，上传许可允许使用的商品资料、清楚参照图、实拍和成品配音。新页面创建的项目默认开启增强素材检查；已有项目须手动开启、保存，再重新识别。旧任务与旧片不会被重新剪辑。

1. 选择本项目的一张商品参照图。建议背景简单，商品外形、口部和部件清楚；参照图只是视觉比对依据，不等于品牌或 SKU 证明。
2. 开启“增强素材检查”，保存后识别素材。检查绑定文件哈希、参照图、检查版本和本机模型；旧观察仍保留，过期结果须重识别。
3. 核对事实和文稿。三份备选稿会分别显示可制作句数、素材缺口和补拍建议；采用备选仍需独立确认文稿。不会为了绕过素材缺口偷偷改写卖点。
4. 三个风格显示整体、细节、场景素材是否支持该方向。这里只说明当前素材适配；时长未对齐时是估计，配音对齐后按实际镜头时长再检查，不自动确认风格。
5. 上传配音或沿用已有合成声音，在本机对齐并人工听核。自动选段要同时满足画面语义、参照外观、主体可见区间、完整动作和非重复源区间。
6. 查看逐镜分镜。可手动改素材、入点、取景和动效；手动选择保留并明确标注，不算机器检查通过。只重做不满意的镜头，生成新版，原片和审核记录保留。
7. 成片仍需人工审核；样片的自动化测试确认只是隔离演练，不代表客户的事实、文稿、风格或听审签收。系统不会自动投放。

## 检查含义与限制

| 检查 | 可做 | 不代表 |
| --- | --- | --- |
| 外观一致 | 比较至少两项永久可见特征；忽略液体、握持和视角变化；有歧义则待核对 | 型号、正品、同一实物或所有角度认证 |
| 主体可见 | 唯一主体、可辨认；有界框面积至少占帧包围面积4%；连续抽样端点内选段 | 商品真实像素覆盖率、构图评分或逐帧无遮挡 |
| 动作完整 | 倒入类流体可见区间须有前后无流体样本；开/合盖须相邻帧位移证据 | 所有商品动作；拿起、折叠、穿戴等仍需补证或人工 |
| 重复 | 同文件内容哈希的源时间区间不自动重叠；重命名不增加可用时长 | 同文件不同区间、跨文件的相似帧仅提示及同分降权，不证明动作重复 |
| 缺口 | 明确缺素材与“证据不足/分配待核对”分开；预算耗尽不伪装缺素材 | 完整的全局剪辑优化或无误识别保证 |

出现“主体不可见”时，先检查参照图、主体大小、遮挡和实际取景；不能把背景空镜标成商品。可以补拍更近、连续、同款的实拍，或逐镜人工调整。出现“动作不完整”时应补入动作开始前和结束后的连续画面，单张动作标签不能替代。

出现“重复区间不足”时，补不同视角/细节/场景的连续素材，或缩短对应句子并重新确认；不要复制文件冒充新镜头。不同文件相似提示须人工判断，不能据此认定抄袭或重复实物。

本机识别速度取决于模型和内存；一次只运行一个模型识别任务。可以取消或重试失败任务，旧结果不被覆盖成通过。无新增云调用，配音服务仍由已有配置和用户选择控制。

补充：弱证据的外观误判可在本机进行主体局部复核，每段最多两次。仅原画面有唯一可辨认、大小达标的主体时才比较局部，保留全帧原判、裁切图和哈希；不会把微小主体先放大再当作达标。局部结果仍需至少两项永久可见特征，无可靠结果继续人工核对。

检查的是源素材抽样；成片布局、裁切和动效是否挡住商品仍须逐镜回看。本期不自动跟踪主体。

参照图若勾选“仅用于核对”，不会被拿来凑成片。非动作句确实缺画面时，可以自行允许这张图入片并重新检查，或补实拍；系统不会自行切换这个选择，图片仍不能替代动作证据。

自动分配会复用同一份本机匹配结果，最多尝试128次候选组合，避免前镜占用后句唯一可用的素材。它不降低匹配分数或外观/动作门槛，也不保证找到所有可能剪法；预算耗尽或候选分配未通过时，逐镜人工安排。

若模型把“看杯身”误作人物动作，有限本机观察规则可在关键帧文字肯定支持且同款/可见区间检查通过时提供编辑建议；收尾规则仅适用指定中性短句。页面理由明确标注“本机观察规则（非模型评分）”，保留原模型分，否定、部位缺失、不确定、参数功效和真实操作不能借此通过，仍需人工回看。

识别速度更新：点击“复核识别”先严格校验并复用原始观察，动作结论重算；需要全新判断时点击“强制重新推理”。页面显示耗时与缓存信息，旧版和人工确认保留。见 复用机制与实测（历史记录或本机文件，未随公开版分发）。
