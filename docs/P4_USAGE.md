# P4：制作样片与投放后复盘

当前交付方向：制作方负责视频与数据复盘，客户自行投放。无需制作方拥有千川账户即可使用脚本、剪辑、人工复核和 CSV 复盘。真实只读 API 授权由客户按其账户条件配置；P3 写入能力保留但默认关闭，不属于当前交付步骤。

## 先看样片

启动：`uv run python -m ecom_video --data var --port 8765`。打开 http://127.0.0.1:8765/samples 。

- 质感展示：暖色背景、慢推近/拉远，顶部字幕。
- 功能与细节演示：明确源视频选段，杯口与杯盖特写，信息式字幕。只有视觉细节演示，没有经过验证的防漏/保温等性能测试。
- 场景转化：桌面情境、横移，结尾引导用户思考风格偏好。

三条均为 20 秒、1080×1920、30fps、H.264/AAC。样片来自虚构商品 AI 图像、确定性运镜、macOS 婷婷语音和自制合成音乐；文件见 `examples/p4/`。每条提供 MP4、无背景音乐版 MP4、SRT、镜头清单、技术 QC。`jobs.json` 对应本地任务；原始版本保留，修订版本另建任务。

这是制作效果演示，不代表客户事实确认、素材商业使用许可或真实广告业绩；人工复核状态仍待用户完成。图片是 AI 生成示意，商品真实型号、细节、功能必须换成客户材料重新核对。

## 编辑步骤

1. 在样片页选择“查看分镜 / 复制编辑”，点击“复制为新草稿”。也可从首页新建手写脚本或由产品资料确认后进入。
2. 一行脚本对应一镜。修改脚本或默认每镜时长后保存会重置分镜；产品来源脚本仍锁定，必须返回产品资料夹重写并确认。
3. 上传图片/视频；音频最多两条，分别用于配音、背景音乐。原视频声音静音。
4. 逐镜选择素材和 1–15 秒时长（总长≤120 秒）。视频入点和出点以源视频秒数填写，超出源时长会拒绝，不自动循环。保存按 30fps 量化到帧。
5. 图片可选择静止、推近、拉远、向左/右横移。完整显示保留全图并补边；填满画幅会裁切，使用 0–1 的水平/垂直焦点调节。图像预览是运镜示意，成片才是最终裁切和字幕效果。
6. 选择三种字幕/成片风格之一。字幕取自原脚本，不能在分镜中绕过产品确认篡改文案。中文采用禁则换行，字幕位于保守安全区；仍需结合目标平台 UI 人工核对。
7. 配音选项：无旁白、上传配音、本机中文配音。macOS 配置可用时显示“婷婷”；本机逐镜合成，按实际语音长度添加起始空隙，不截断；语音太长会报错，请延长该镜或缩短文案。140–280 语速是系统合成参数，不能理解为精确中文每分钟字数。
8. 可指定另一音频作为 BGM，采用响度处理、淡入淡出和旁白侧链压低；保留无 BGM 版。配音增益 -12～6 dB，音乐目标 -40～-10（近似 LUFS，混音后会受压低影响）。不要将背景音乐误选成旁白。
9. 保存分镜，再提交生成。任务固化脚本、素材哈希、分镜方案及版本；生成后进入人工复核。SRT 本机语音采用逐镜实测时间，非逐字强制对齐；上传旁白按人工分镜时间，需对轴检查。

旧 P0–P3 已提交快照不带分镜方案，继续使用旧渲染逻辑。新版工作台生成时会保存当前显示的分镜，即使未改动默认值；直接调用旧 API 且不提交分镜的集成保留兼容逻辑。旧视频元数据会在渲染前重新探测；无法核验画面时长的文件请重新导出标准 MP4。

## 客户投放与复盘

网页操作指南： http://127.0.0.1:8765/guide 。

1. 制作方完成人工成片复核，交付 MP4、字幕、镜头清单、来源与版本；可选从复盘页底部导出交付包。
2. 客户在自己的平台账户确认商品、素材使用权限、AI 标识、预算、出价和排期，自行上传与投放，跟进平台审核。
3. 客户记录广告主 ID、素材 ID、计划 ID 与成片版本。复盘使用素材 ID，不能拿计划 ID 代替。
4. 客户导出全部素材的完整日粒度报表。制作方从复盘页下载 CSV 模板，把字段转换为：

   `date,material_id,spend,impressions,clicks,orders,revenue,video_views,completed_views`

5. 选定客户账户和日期范围、填写导入人并确认完整性，导入 CSV。无需先创建本地投放任务。金额 CNY、时区 Asia/Shanghai，orders/revenue 使用支付订单/支付金额；缺失字段留空，不补零。
6. 关联平台素材 ID 与已审核本地成片，查看逐日/逐素材指标和来源。新批次完整覆盖所选范围；相同文件+范围重复导入不会累加。
7. 同口径、相近投放条件下比较开场、镜头、配音和 CTA；把下一轮改动记录为新草稿。支付 ROI 不等于利润率，描述性相关不证明某种风格带来增量转化。

平台接口保留说明见 P3_USAGE.md；真实账户联调仍未验证。CSV 优先，不需要 App ID/Secret。客户选择只读接口时自行配置凭据，保持 `ECOM_QIANCHUAN_WRITES` 未设置。当前本机没有启用广告上传或创建。

## 恢复与边界

SQLite 从 v4 增量迁到 v5，仅新增两列，不改旧快照。P3 恢复快照在 `var/backups/p3-before-p4/`；回退须停服务、先保存 P4 数据，再成对恢复旧源码与旧数据库，旧程序不能直接读取 v5。

本版不含拖拽非线性时间线、逐字 ASR 对齐、云端 TTS、真人录制、I2V、多用户、自动合规保证或自动广告优化。客户实际素材替换与最终审美/语音质量验收仍需完整观看和试听。
